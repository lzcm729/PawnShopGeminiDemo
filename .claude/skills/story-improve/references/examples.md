# 叙事示例与代码模式

## 好的叙事 vs 坏的叙事

### 坏的叙事

```
Day 1: NPC来了，玩家帮了她
Day 5: NPC又来了，更惨了
Day 10: NPC自杀了
玩家："？？？我做错了什么？"
```

**问题**：
- 玩家完全不知道 Day 1-5 之间发生了什么
- 状态恶化没有任何铺垫
- 坏结局突然发生，玩家无法追溯原因

### 好的叙事

```
Day 1: NPC来了，玩家帮了她
Day 2: [邮件] "谢谢你，我今天面试感觉不错"
Day 4: [邮件] "面试被拒了，但我不会放弃"
Day 5: NPC又来了，对话体现疲惫但仍有希望
Day 7: [邮件] "他开始抱怨我了..."
Day 10: NPC来了，神情恍惚，玩家能理解为什么
玩家："我早该多帮帮她的..."
```

**优点**：
- 邮件填补了"消失期间"的信息空白
- 状态变化有递进铺垫
- 坏结局的因果链对玩家可见

## exitDialogues 条件变体示例

### 好的设计：利用条件变体铺垫未来

```typescript
exitDialogues: {
    grateful: [
        { condition: { variable: "hope", operator: ">=", value: 60 },
          text: "谢谢！我回去告诉男朋友这个好消息！" },
        { text: "谢谢你！" }
    ],
    resentful: [
        { condition: { variable: "hope", operator: "<", value: 30 },
          text: "[低着头] 回去又要被他骂了..." },
        { text: "..." }
    ]
}
```

**优点**：
- 根据 hope 变量选择不同台词
- 高 hope 时暗示"男朋友"是支持者
- 低 hope 时暗示关系紧张，铺垫后续冲突

### 浪费的设计：只用固定文本

```typescript
exitDialogues: {
    grateful: "谢谢。",
    resentful: "..."
}
```

**问题**：
- 浪费了即时反馈的机会
- 没有利用条件变体展示状态差异
- 玩家无法通过对话感知 NPC 状态

## 邮件系统的作用

邮件主要用于填补 **NPC 消失期间** 的信息空白：

| 类型 | 作用 | 示例 |
|------|------|------|
| 交易后即时反馈 | 让玩家知道决策的即时影响 | "谢谢你帮我，这笔钱够交房租了" |
| 阶段性状态更新 | 填补消失期间的信息空白 | "这周投了20份简历，只有一家回复..." |
| 事件预告 | 让下一次出现有心理准备 | "明天我要去面试，希望顺利" |
| 结局解释 | 让好/坏结局的原因可追溯 | "如果不是你当初帮我，我可能撑不到今天" |

## description 递进示例

### 好的递进：反映 NPC 状态变化

```typescript
// Stage 0
description: "一位穿着精致职业装的年轻女性，妆容得体，但眼神中有一丝焦虑。"

// Stage 1
description: "艾玛看起来比上次憔悴了一些，妆容简单了许多，但还是努力保持着整洁。"

// Stage 2
description: "艾玛的黑眼圈很重，头发有些凌乱，衣服上有明显的褶皱。她的手微微发抖。"

// Stage 3 (低 hope)
description: "艾玛几乎认不出来了。蓬头垢面，眼神空洞，机械地站在柜台前。"
```

### 问题：全程不变

```typescript
// 所有阶段都用同一个 description
description: "一位年轻女性。"
```

**问题**：玩家无法通过外观感知 NPC 状态的恶化

## fateHints 示例

```typescript
// 在 fateHints 配置中
{
    chainId: 'emma',
    variable: 'hope',
    ranges: [
        { min: 70, max: 100, hint: '（她的眼中还有光芒，对未来充满期待）' },
        { min: 40, max: 69, hint: '（她在强撑着微笑，但疲惫已经写在脸上）' },
        { min: 20, max: 39, hint: '（她的眼神有些涣散，像是在想着别的事情）' },
        { min: 0, max: 19, hint: '（她的眼睛红肿，像是刚哭过。嘴唇在微微颤抖）' }
    ]
}
```

**作用**：让隐藏变量 (hope) 通过可见的观察提示反映给玩家
