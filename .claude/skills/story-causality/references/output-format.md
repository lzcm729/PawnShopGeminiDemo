# 输出格式规范

## 概览层

```
story-causality 报告：[事件链名称]

输入来源：docs/story-validations/[chain_name]-validation-[timestamp].md

决策点结构：典当1 → 衍生? → 结算1 → 典当2? → 结算2? → 结局
路径总数：X 条（其中 Y 条到达结局，Z 条中途终止）

┌──────────────────────────────────────────────────────────────┐
│ 路径                                    │ 收束 │ 盲区 │ 优先级 │
├──────────────────────────────────────────────────────────────┤
│ 90%×0% → 同意 → 赎回 → 90%×0% → 赎回 → 脱困 │ ✓    │ 1   │ 低     │
│ 90%×0% → 同意 → 赎回 → 80%×10% → 失败 → 破产 │ ✗    │ 4   │ 高     │
│ 70%×20% → - → [不出现] → 绝望            │ ✗    │ 5   │ 高     │
│ ...                                                          │
├──────────────────────────────────────────────────────────────┤
│ 整体感知盲区汇总：                                            │
│ • 临界点不可见：X 条路径                                      │
│ • 结果缺乏行为归因：Y 条路径                                  │
│ • 多决策累积效应不透明：Z 条路径                              │
└──────────────────────────────────────────────────────────────┘
```

**收束评估符号**：
- `✓` 收束成功
- `△` 部分收束（有盲区但主因果可见）
- `✗` 收束失败

**优先级**：基于盲区数量和收束评估
- 高：收束失败 或 盲区≥4
- 中：部分收束 或 盲区2-3
- 低：收束成功 且 盲区≤1

## 路径表达规范

与 story-validator 输出格式保持一致：

**完整路径**：
```
Day 1: 典当节点 - 职业套装 [90% × 0%]
  └─ hope: 50→70, funds: +900
Day 5: 物品衍生节点 - 借用电脑 [同意]
  └─ job_chance: +20
Day 8: 结算节点 - 套装续当 [同意]
Day 10: 典当节点 - 电脑 [80% × 10%]
  └─ hope: 70→60
Day 15: 结算节点 - 赎回 [无力]
  └─ 结局: 破产
```

**简化路径**：`90%×0% → 同意 → 赎回 → 80%×10% → 失败 → 破产`

**中途终止**：`70%×20% → [NPC不出现] → 绝望`

**跳过节点**：`90%×0% → - → 赎回 → 脱困`（表示该节点未发生）

## 节点类型标记

| 节点类型 | 标记 | 参数格式 |
|----------|------|----------|
| 典当节点 | `典当节点 - [物品]` | `[当金% × 利率%]` |
| 结算节点 | `结算节点 - [物品][场景]` | `[决策]` |
| 物品衍生节点 | `物品衍生节点 - [行为]` | `[同意/不同意]` |

**利率档位**：0% / 5% / 10% / 20%（客观参数，不绑定意图标签）
