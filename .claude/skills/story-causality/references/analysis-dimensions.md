# 因果分析六维度

## 1. 决策序列与行为空间

记录路径中每个节点：

```
节点1 - 典当节点（90% × 0%）
  行为空间：当金 70%~100%，利率 0%/5%/10%/20%
  NPC状态：hope 30→50，funds 0→900

节点2 - 物品衍生节点（同意借用）
  NPC状态：hope 50→60，job_chance +20

节点3 - 结算节点（赎回/同意）
  条件：NPC funds ≥ 赎回金额
  NPC状态：hope 60→65，funds 3000→2100
```

**关键**：
- 行为空间用客观参数描述：当金% × 利率%
- 意图（怜悯/公办/压榨）是玩家的主观动机，与利率独立
- 因果分析时从行为推断意图，而非假设利率=意图

## 2. 因果链追踪

绘制行为→演化→结果的因果链：

```
典当1      衍生       结算1      典当2      结算2      结局
90%×0%    (同意)     (赎回)    80%×10%    (失败)
          借用电脑    同意                 无力赎回
  │         │          │          │          │         │
  ▼         ▼          ▼          ▼          ▼         ▼
hope+20  job+20%    funds-2100  利息压力   物品流当    破产
funds+900 信任建立   hope+5     hope-10    hope-25
```

标注：
- 每个决策对NPC状态的直接影响
- 影响如何累积导致最终结果
- 关键转折点在哪里

## 3. 关键分叉点识别

找出"改变命运"的临界点：

```
关键分叉点：
• 典当1：当金 ≥85% vs <85% → 决定NPC能否撑到下次收入
• 物品衍生：同意借用 vs 拒绝 → 决定job_chance能否提升
• 典当2：利率 ≤5% vs >5% → 决定NPC能否负担赎回
```

**检查**：玩家是否知道这些分叉点存在？

## 4. 暴露点检查

检查每个节点后，因果关系是否被叙事内容暴露：

```
典当1后：
  ✓ 对话："谢谢你愿意帮我"（暴露：帮助被感知）
  ✗ 无内容提及金额是否足够

物品衍生后：
  ✓ 邮件："有了电脑我可以继续投简历"（暴露：借用的价值）
  ✗ 无内容提及 job_chance 提升

典当2后：
  ✗ 无内容提及利率压力
  ✗ 无对比"这次条件比上次..."

结局：
  ✗ 破产通知没有回溯任何决策
```

**暴露机制**：对话、邮件、fateHints（外观变化）、news。

## 5. 感知盲区

汇总玩家无法感知的因果关系：

| 盲区类型 | 示例 |
|----------|------|
| 临界点不可见 | 不知道当金85%是分水岭 |
| 演化过程不透明 | 不知道NPC日常消耗速度（funds -50/天） |
| 决策影响未归因 | 第二次利率的影响未被提及 |
| 累积效应不可见 | 不知道多次决策如何叠加影响 hope |
| 利率后果不透明 | 不知道不同利率对NPC心态的具体影响 |

## 6. 收束评估

评估玩家能否完成意图收束：

**收束成功的标志**：
- 玩家看到结果时，能追溯到自己的哪个决策
- 玩家能理解"如果当时选择不同，结果会怎样"
- 玩家不会把结果归因于"运气"或"命运"

**收束失败的症状**：
- 玩家感到"突然就失败了"
- 玩家不知道"我做错了什么"
- 玩家归因于系统不公平

**评估格式**：
```
问题：玩家能否理解"为什么两次交易还是失败了"？

结论：✗ 因果链断裂

断裂点：典当2（80%×10%）的利率影响未被暴露

玩家可能的归因：
  ✗ "命运不好"（错误）
  ✗ "第一次没帮够"（错误）
  ? "第二次利率太高"（正确，但无证据）

修复方向：
  → 在典当2后添加邮件，提及利息压力
  → 在结局添加回溯对话，引用具体决策
```
