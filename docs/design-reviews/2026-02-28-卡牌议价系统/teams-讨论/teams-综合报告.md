## 跨议题共识汇总

### 1. 六区间隐性声誉映射（议题1 核心产出）

| 区间 | 利率 | 人情 | 商誉 | 清白 | 精魄 |
|------|------|------|------|------|------|
| CHARITY (恩惠) | 0% | +2(主动)/+1(被动) | 0 | 0 | 灵韵+4 |
| AID (公道) | 1%-4% | +1(慷慨)/0(普通) | +1 | 0 | 灵韵+2 |
| STANDARD (精明) | 5%-9% | 0 | +1 | 0 | 匠心+1~+2 |
| ELEVATED (偏高) | 10%-14% | 0 (纯叙事信号) | +1 | 0 | 匠心+1 |
| HIGH (贪婪) | 15%-19% | -1 | 0 | -1 | 旧影+2 |
| SHARK (掠夺) | 20%+ | -3 | -2 | -2 | 旧影+4 |

- 区间内声誉持平，叙事层渐变文案
- 分层可见性：大部分隐性 + 10%半显性 + 20%道德地震（每存档首次）
- 0%成交金色光晕（善良仪式感）
- 赎回率独立连续函数

### 2. 手牌位竞争消耗池模型（议题2 核心产出）

- 鉴定消耗卡/洞察消耗卡独立存在，通过牌组空间+手牌位（5张上限）形成天然共享竞争
- 消耗卡每日重置，消耗完后有弱化版普通卡软降级
- 临时卡（共情/试探/特征卡）回合末不弃置但占手牌位——"知道了就无法假装不知道"
- 信息-工具时间分离：洞察本轮给信息，剥削工具下轮才可用

### 3. 精度收益D方向主锚（议题2 核心产出）

- D替代（经济卡效果修正+20%~40%）为主锚——即时、可量化、可归因
- C'保留（黑市波动）
- A2替代（耐心消耗修正）为P1辅助
- A1替代（掉牌质量修正）降为P2
- 卡面动态显示精度加成数值

### 4. 可量化偏差是设计特性（议题2 核心洞察）

- 玩家自然偏好鉴定（可量化经济收益）、忽视洞察（不可量化道德收益）
- 这映射"生存压力使人忽视他人"的核心主题
- 通过夜间"叙事FOMO"和早期教学事件建立洞察的内在动机

## 总体评价

两个跨系统议题的讨论产出了高质量的融合方案：

**议题1** 解决了整合评估中最关键的P0问题——连续利率与声誉系统的映射断裂。六区间方案在保持道德滑坡"温水煮蛙"体验的同时，为所有下游系统提供了清晰的判定框架。分层可见性模型（道德地震）是一个创新的设计，值得在v0.2中实现。

**议题2** 解决了第二个P0问题——AP竞争消失后的资源决策空洞化。手牌位竞争模型优雅地利用了卡牌系统的天然约束，无需额外机制层。behavioral-economist 提出的"可量化偏差是feature"洞察为洞察系统的定位提供了全新视角——不需要强制平衡鉴定和洞察的使用率，而是利用这种不平衡来服务核心叙事。

**两个议题的产出可以直接整合进卡牌议价系统 v0.2 的设计文档。** 议题1的六区间映射还需要同步更新声誉系统和人物能力系统的相关章节。
