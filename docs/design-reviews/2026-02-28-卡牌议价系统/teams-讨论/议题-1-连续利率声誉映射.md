# Teams 跨系统讨论报告 — 议题1

> **日期**: 2026-02-28
> **议题**: 连续利率取代四档合同后，声誉三轴的映射规则如何重新定义？
> **涉及文档**: 卡牌议价系统 + 声誉系统 + 人物能力系统
> **参与成员**: systems-balancer, moral-designer, narrative-integrator

---

## 三方共识

### 共识 1: 采用六区间隐性离散映射，拒绝纯连续函数

- **结论**: 连续利率在声誉系统中映射为六个隐性离散区间（CHARITY/AID/STANDARD/ELEVATED/HIGH/SHARK），对玩家不可见。区间内声誉效果持平，叙事层允许渐变文案。
- **理由**: 三方一致认为纯连续函数的声誉变化过于微小不可感知，且下游系统（人物能力、精魄加成）需要离散判定。六区间比五地标多出 ELEVATED(10%-14%) 区间，提供更平滑的道德梯度。

### 共识 2: 六区间划分方案

| 区间 | 利率范围 | 声誉效果 | 精魄加成 |
|------|---------|---------|---------|
| **CHARITY (恩惠)** | 0% | 人情 +2(主动善良)/+1(被动善良) | 灵韵 +4 |
| **AID (公道)** | 1%-4% | 人情 +1(慷慨)/0(普通), 商誉 +1 | 灵韵 +2 |
| **STANDARD (精明)** | 5%-9% | 商誉 +1 | 匠心 +1~+2 |
| **ELEVATED (偏高)** | 10%-14% | 商誉 +1, 人情 0 (纯叙事信号) | 匠心 +1 |
| **HIGH (贪婪)** | 15%-19% | 人情 -1, 商誉 0, 清白 -1 | 旧影 +2 |
| **SHARK (掠夺)** | 20%+ | 人情 -3, 商誉 -2, 清白 -2 | 旧影 +4 |

- **来源**: systems-balancer 提出六区间框架，moral-designer 同意并补充分层可见性，narrative-integrator 从五区间修正为六区间。

### 共识 3: 阈值感知以叙事为主、数值为辅，信号强度递增

- **结论**: 区间跨越的感知设计遵循"前轻后重"原则——早期跨越几乎无感（温水煮蛙），后期跨越强烈感知（道德地震）。叙事反馈（商人独白、客户反应）是主要感知通道，数值跳变是结构性后果。
- **理由**: 三方一致认为数值跳变太大会产生"惩罚感"而非"沦陷感"，与道德滑坡的核心体验冲突。声誉系统v2.4的三层反馈架构天然支持分层感知设计。

### 共识 4: 感知分层设计

| 跨越 | 可见性 | 即时信号 | 叙事信号（延迟） |
|------|--------|---------|----------------|
| CHARITY→AID (0%→1%) | 隐性 | 声誉条微变 | 商人独白焦点转向"交易" |
| AID→STANDARD (4%→5%) | 隐性 | 声誉条微变 | 独白语气微变 |
| STANDARD→ELEVATED (9%→10%) | **半显性** | 客户表情变化 + 独白自问 | 新闻/邮件相关内容 |
| ELEVATED→HIGH (14%→15%) | 隐性→延迟叙事 | 声誉条变化 | NPC情绪首次可见变化 + 邮件 |
| HIGH→SHARK (19%→20%) | **显性（道德地震）** | 客户反应剧变 + 独白质变 + 画面微变 | 新闻标题变化 + 多封邮件 |

- **来源**: moral-designer 提出分层可见性模型和"道德地震"概念，systems-balancer 提出信号强度递增原则，narrative-integrator 提出"前轻后重"兴趣曲线。

### 共识 5: 赎回率使用连续函数，独立于地标跳变

- **结论**: 赎回率改为连续函数 `baseRate × (1 - rate × 0.02)`，不与声誉区间耦合。
- **理由**: 赎回率是经济系统的连续变量，不应因声誉区间的离散化而产生不自然的阶梯效应。

### 共识 6: 下游适配优先级——道德传导链完整性原则

三方一致同意按"道德传导链完整性"排序适配优先级：

**P0 (v0.2 必须同步):**
- 声誉行为影响矩阵：四档→六区间查表
- 精魄道德加成：四档→六区间映射
- 惜物如人触发条件：改为利率 <= 3%~4%

**P1 (v0.2 应同步):**
- 口口相传判定：基于惜物如人触发
- 因果自见：v0.2保留命运闪现，v0.3实现卡牌边界预兆
- 商人直觉文案框架（架构先行，文案可后补）

**P2 (v0.3 延后):**
- 完整的六区间×NPC类型文案矩阵
- 道德回声框架细化
- 夜间回望机制
- 区间内渐变叙事文案

## 分歧与权衡

### 分歧 1: ELEVATED 区间是否产生数值惩罚 → **已解决**

- **最终共识**: ELEVATED 区间纯叙事信号，人情 0。声誉负面效果从15%才开始。
- systems-balancer 在交叉讨论中接受了 narrative-integrator 的论点：10%在旧系统中是"标准档"中性基准，10%-14%区间通过叙事信号（商人独白"合理化"语气）传递道德偏移感知，不需要数值惩罚。
- **新增共识：恩惠区分主动/被动** — 被动善良（未打经济卡+0%利率）人情+1，主动善良（打了[+当金]让利卡+0%利率）人情+2。

### 分歧 2: 边界处理——硬切 vs 概率渐变

- **systems-balancer**: 硬切（简洁，下游系统只需一次区间查询）
- **narrative-integrator**: 概率渐变（边界附近2-3%宽的模糊带，防逆向工程，维护温水煮蛙体验）
- **moral-designer**: 未明确表态
- **建议**: v0.2先用硬切（实现简单），测试中观察玩家是否逆向工程出精确边界，必要时v0.3升级为渐变

### 分歧 3: HIGH 区间(15%-19%)是否扣清白

- **moral-designer**: 质疑HIGH区间扣清白——清白轴定义为"法律面前的你"，15%利率虽道德有问题但不违法
- **systems-balancer**: 原方案中HIGH区间清白-1
- **建议**: 需要用户裁决清白轴的语义边界。如果严格限定为"法律行为"，则只有SHARK(20%+)扣清白；如果广义理解为"社会规范"，HIGH可扣清白-1

### 分歧 4: 惜物如人触发阈值

- **systems-balancer**: <= 3%（比公道区间边界更严格，体现"善行需要额外代价"）
- **moral-designer**: <= 4%（与AID区间上界对齐）
- **narrative-integrator**: <= 4%（与AID区间上界对齐）
- **建议**: 需要用户裁决。3%更严格但增加善良难度，4%与区间边界一致更直观

### 分歧 5: 商人直觉文案矩阵的优先级

- **moral-designer**: P0（商人独白是玩家感知道德位移的主要通道，断裂后道德地震无法实现）
- **systems-balancer**: P2（内容创作量大，可暂用默认文案兜底）
- **narrative-integrator**: 架构P0 + 文案P2（框架必须v0.2建立，60条文案可后续填充）
- **建议**: 采纳narrative-integrator的折中方案——v0.2建立"基调+修饰词"框架+每区间2-3条基础文案，v0.3完善全量文案

### 分歧 6: 回望机制的形式

- **systems-balancer**: 夜间道德轨迹柱状图（纯数据展示）
- **moral-designer**: 夜间叙事化总结（非柱状图，用叙事语言描述道德轨迹）
- **建议**: P2延后，两种形式可共存（柱状图+叙事化总结文案）

## 融合方案

### 方案 1: 六区间 + 分层可见性 + 叙事为主的声誉映射体系

- **描述**: 连续利率映射为六个隐性离散区间，区间边界对玩家不可见。区间内声誉效果持平，叙事层提供渐变文案。阈值跨越的感知信号从隐性递增到显性（道德地震），确保道德滑坡的"温水煮蛙"体验。赎回率独立使用连续函数。
- **涉及系统**: 声誉系统（行为矩阵重构）、人物能力系统（技能触发阈值适配）、精魄系统（道德加成映射）、商人直觉（文案矩阵扩展）、卡牌议价系统（利率→区间判定输出）
- **来源**: systems-balancer 的六区间框架 + moral-designer 的分层可见性模型和道德地震概念 + narrative-integrator 的前轻后重感知曲线

### 方案 2: 0%成交金色光晕（善良仪式感）

- **描述**: 0%利率成交时触发金色光晕视觉效果，让善良行为具有"主动仪式感"而非"被动不做恶"。解决卡牌系统中"善良=什么都不做"的问题。
- **涉及系统**: 卡牌议价系统（成交视觉反馈）
- **来源**: moral-designer

### 方案 3: 因果自见分阶段实现

- **描述**: v0.2保留"决策后命运闪现"（不依赖合同档位），v0.3实现完整的"打牌前卡牌边界预兆"（地标边界-1%时卡牌边缘预兆，仅恶化方向）。
- **涉及系统**: 人物能力系统（因果自见技能）、卡牌议价系统（卡牌UI预兆效果）
- **来源**: systems-balancer 提出预兆方向约束 + narrative-integrator 提出分阶段策略
