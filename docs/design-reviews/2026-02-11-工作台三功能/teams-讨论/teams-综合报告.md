## 一、跨议题核心共识

以下共识跨越多个议题，代表三方最坚定的设计立场：

### 1. "造假不犯法，卖假才犯法"——惩罚延迟原则

**议题1+2联合结论**：死当伪造操作本身 **0清白**，惩罚推迟到出售时（-4清白）。操作到出售之间形成"悬而未决"的道德窗口。当期伪造操作 -3（破坏受托财产）。

### 2. 概率恒定原则——信息改变认知不改变现实

**议题3核心结论**：归还概率由 objectiveWeight 决定，**不受玩家信息完备度影响**。信息投入的价值在于"更知情的赌注"和跨物品"选品"能力，不是"更好的赌注"。

### 3. 永远允许操作——摩擦不是墙

**议题2+3联合结论**：不可能三角通过资源竞争（精魄/精力）实现，不通过"做A扣B"实现；所有工作台操作始终可用，信息缺失增加叙事摩擦但不锁定选项。

### 4. 反向交叉递增——利用人类心理而非对抗它

**议题1核心模型**：心理/叙事成本从高到低（习惯化不可避免），数值/机械成本从低到高（世界在回应）。当内心已麻木时，外部后果加剧。

### 5. 叙事化一切——数据面板是最后手段

**议题2+3联合立场**：声誉反馈分三层（即时微反馈→叙事化反馈→状态总览）；工作台信息通过"商人回忆独白"传递不通过数据面板；持久化数据可以丰富但玩家看到的永远是一句话。

## 二、三议题关键成果汇总

### 议题 1：伪造品经济链条

| 成果 | 内容 |
|------|------|
| **定价公式** | `底材价值 × min(max(标签系数) + (次高-1)×0.5, 5.0) × 出售系数 × 0.75折扣 × (1-佣金) × 鉴伪修正` |
| **三通道风险** | A.机械（鉴伪15%+3%/次 cap33%）+ B.声誉（清白侵蚀）+ C.叙事（里程碑事件） |
| **伪造声名** | 隐藏变量，四阶段：试水(1-3)→入行(4-7)→老手(8-12)→声名在外(13+)，不可衰减 |
| **凝视递减** | 5秒→3秒→1秒→消失（议题2修订为→2秒沉默） |
| **违约赔偿** | "合同审计"阶梯：当金/估价比越低，赔偿倍率越高（200%→400%） |

### 议题 2：声誉框架统一

| 成果 | 内容 |
|------|------|
| **完整声誉表** | 修复(1轴H) < 重铸(2轴H+C) < 伪造(3轴H+C+I)，轴暴露梯度与风险对齐 |
| **术语修订** | "黑道"→"清白(Innocence)"；"感动"→"叹服" |
| **伪造违约差异化** | 普通违约(H-15,C-10) vs 伪造违约(H-15,C-12,I-5) |
| **凝视进化** | 内容从道德不安→自我合理化→职业麻木→沉默，保持2秒最低时长 |
| **三层反馈架构** | 即时微反馈(方向) + 叙事化反馈(因果) + 状态总览(数值) |

### 议题 3：信息数据流

| 成果 | 内容 |
|------|------|
| **双层模型** | objectiveWeight(系统真实值，决定概率) + perceptionTier(玩家感知，决定叙事丰富度) |
| **emotionalWeight** | 三档离散化(低/中/高)，输入：trait + 对话 + 洞察 + BehaviorTag |
| **perceptionTier** | 四档内部(blind/glimpse/partial/clear) → 三档叙事呈现(匮乏/部分/完备) |
| **持久化方案** | 交易结算时一次性快照到物品(PawnCustomerSnapshot) + 独立CustomerMemory |
| **自强化闭环** | 鉴定/洞察→信息存储→工作台直觉→决策→归还结果→归因学习→行为改变 |

## 三、议题间修订链

后续议题对前序议题结论的修订：

| 原结论（来源） | 修订为（来源） | 原因 |
|---------------|---------------|------|
| 死当伪造操作 清白-1（议题1） | 操作0 + 出售-4 = -4/周期（议题2） | "造假不犯法，卖假才犯法"；悬念窗口 |
| 当期伪造 清白-3/次（议题1） | 操作-3 + 出售-4 = -7/周期（议题2） | 当期操作扣分+出售扣分分离 |
| 凝视从5秒递减至消失（议题1） | 凝视从5秒递减至2秒沉默，内容进化（议题2） | 沉默比消失更有力量 |
| "物品情感分量"未定义（整合评估） | 三档离散化 + 积分计算（议题3） | 完整定义了数据来源和计算规则 |
| 重铸归还概率依赖未定义数据（议题2） | 概率由objectiveWeight决定，不受perceptionTier影响（议题3） | 概率恒定原则 |
| 伪造凝视仅依赖次数（议题1） | 凝视文案额外受perceptionTier影响（议题3） | 信息状态影响凝视氛围 |
