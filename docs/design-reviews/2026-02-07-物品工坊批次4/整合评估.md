# 物品工坊批次4 -- 9视角整合评审

> **评审日期**: 2026-02-07
> **评审对象**: 物品变体与标签系统 (初稿)、重铸与修复系统 (初稿)、格物与精魄系统 (v1.0)
> **评审方法**: 9 个并行 game-designer Agent，分别从数值一致性、系统间交互、优雅性、决策质量、动机强化、玩家体验、技能深度等视角评审，结果整合
> **评审文件**: 物品变体标签(3篇) + 重铸修复(3篇) + 格物精魄(3篇)

---

## 一、多视角共识问题

### 共识 1: 重铸暴利率失控 -- 经济系统的根本性风险

| 视角 | 发现 |
|------|------|
| **标签-数值一致性** | IMPERIAL x10.0 + BROKEN x0.1 构成 $50->$10,000 的套利路径，ROI 高达 8900%。修复/重铸路线日均收益 $800-2600 vs 纯交易 $87，修复/重铸严格主导。 |
| **重铸-数值一致性** | 文档示例 $50->$4,500 (90x)、$2,000->$20,000 (10x)。6-22 次重铸即可通关 $100,000 目标。重铸成为 dominant strategy，典当议价被架空。 |
| **重铸-决策质量** | 重铸收益规模碾压日常经营（10-90 倍 vs 1 倍），理性玩家将所有资源投入重铸流水线，议价的推拉博弈、合同道德选择沦为"采购底材的前置工序"。 |
| **重铸-动机强化** | 奖励未对齐：囤货格物/重铸 vs 急需变现的生存压力。如果重铸暴利，日常交易被边缘化，格物变成唯一有意义的夜间活动。 |
| **格物-数值一致性** | 修复 ROI ($30/点) vs 重铸 ROI ($60/点)，重铸严格优于修复。消费端参数完全缺失，无法验证"3-5天积攒"目标。 |

**核心问题**: IMPERIAL x10.0 的倍率使重铸成为碾压所有其他玩法的唯一最优策略。典当交易（游戏核心循环）的经济意义被完全架空。按当前数值，一次成功重铸的收益等于正常经营 14-34 天。这不是微调问题，而是经济模型的根本性失衡。

**涉及文档**: 物品变体与标签系统(发现2,12)、重铸与修复系统(发现1,5,7,12)、格物与精魄系统(发现2,8)

### 共识 2: 消费端数值全面缺失 -- 无法做任何平衡验证

| 视角 | 发现 |
|------|------|
| **标签-数值一致性** | DIRTY、CURSED、TRENDING 等标签缺乏价值系数定义。G2 标签"权重"概念未定义。 |
| **重铸-数值一致性** | 修复和重铸的点数消耗、精力消耗全部缺失。仅有散落示例值（100旧影+20匠心），无系统化参数表。精力竞争（格物/修复/重铸/修行四者争抢）未量化。 |
| **重铸-决策质量** | 重铸配方的信息完全空白：有哪些配方、各需多少点数、产出预期价值均未定义。构成 Sylvester 信息饥饿问题。 |
| **格物-数值一致性** | 产出端已知（20点/次，3精力/晚），消费端仅有散落示例。顿悟暴击比例在文档三处出现三个不同数值（20%/30%/40%）。 |

**核心问题**: 三个系统共同构成"产出->消费"的经济闭环，但消费端几乎是空白。没有配方参数表，无法验证任何平衡假设（如"3-5天积攒"、"修复门槛低"、"重铸是大招"）。设计文档处于"概念验证"阶段，距离可实现的数值平衡还需完整的参数定义。

**涉及文档**: 全部三个系统

### 共识 3: 乘法叠加缺乏边界保护 -- 极端值风险

| 视角 | 发现 |
|------|------|
| **标签-数值一致性** | 乘法公式 `基础价值 x 连乘(标签系数)` 无上下限保护。两个 x10 标签叠加 = x100。G3 标签互斥规则未定义。 |
| **标签-系统间交互** | 极端叠加（IMPERIAL x10 + TRENDING x? + LIMITED x?）可能产生 $100,000+ 物品，等于游戏胜利目标。 |
| **标签-优雅性** | 乘法公式在简洁性上是优雅的，但指数增长的数学特性使两个高倍标签相乘可能产生 x100+ 的极端值。建议 G3 互斥。 |
| **重铸-数值一致性** | 全部标签系数仅定义了 3 个（BROKEN x0.1, IMPERIAL x10.0, GOLD x1.0），其余均空白。 |

**核心问题**: 乘法公式是优雅的架构选择，但缺少两项关键配套：(1) G3 标签互斥规则或数量上限；(2) 最终价值的 clamp 上下限。必须在标签系数表完善之前先确定这两项约束。

**涉及文档**: 物品变体与标签系统(发现3,11)、重铸与修复系统(发现11)

### 共识 4: FAKE_HISTORY 赝品识破风险缺失 -- 道德困境被架空

| 视角 | 发现 |
|------|------|
| **标签-数值一致性** | FAKE_HISTORY 与鉴定系统 FAKE 的语义冲突。缺乏买方鉴伪机制，FAKE_HISTORY 可能是纯收益零风险的印钞机。 |
| **标签-优雅性** | FAKE_HISTORY 是涌现潜力最高的标签，但如果永远不被识破，就只是无风险的"钱倍增器"，削弱道德困境的重量。建议增加 detection_risk 字段。 |
| **重铸-数值一致性** | 赝品出售渠道和定价机制未定义。如果按标签价值 80% 直接变现，路径过于确定和暴利。 |
| **重铸-决策质量** | 被识破风险标注为"未来功能"。初版无风险 = 重铸一切是显而易见的最优策略（信息过载/假决策）。 |

**核心问题**: FAKE_HISTORY 是道德系统的核心试金石 -- "造假获利"应该充满紧张感。但如果没有被识破的概率，造假就是无风险套利，"道德困境"变成了"何乐而不为"。识破机制不应是"未来功能"，而应是赝品系统的基础组件。

**涉及文档**: 物品变体与标签系统(发现6)、重铸与修复系统(发现8)

### 共识 5: 格物操作缺乏交互深度 -- 夜间核心玩法的根基问题

| 视角 | 发现 |
|------|------|
| **格物-玩家体验** | 格物操作只是"点击按钮->看数字变化"。3精力分配可在 30 秒内完成，无法撑起"沉浸式探索"定位。与叙事承诺"与物品对话"严重脱节。 |
| **格物-技能深度** | 格物在 Sylvester 再发明三层模型中跳过了"操作层"(Manual)。每次操作无"做得好/做得差"区别，操作本身是 Nondecision（非决策）。 |
| **重铸-决策质量** | 工作台操作只有 Profound 层决策，缺乏 Twitch 和 Tactical 层混合。所有操作是线性选择序列，节奏单一。 |
| **重铸-动机强化** | 工作台缺少 Twitch 层快速决策调节节奏，完全没有快速反馈层可能让操作感觉"迟钝"。 |

**核心问题**: 夜间被定位为"核心玩法的另一半"，但当前格物/工作台的操作深度远不如白天的鉴定/议价。白天有推拉议价、耐心管理、鉴定博弈等丰富交互；夜间只有"选物品->点按钮->看数字"。如果不增加操作层的决策维度，夜间可能退化为"打卡点名"。

**涉及文档**: 格物与精魄系统(玩家体验-发现1, 技能深度-发现3)、重铸与修复系统(决策质量-发现4)

---

### 共识 6: 动机真空期 -- 固定比率强化的3-5天"无聊地带"

| 视角 | 发现 |
|------|------|
| **重铸-动机强化** | 重铸是典型固定比率强化（Fixed Ratio Schedule），Day 3-4 积累期为动机真空。缺乏叠加强化计划(Superimposed Schedules)。 |
| **格物-玩家体验** | 精魄积累期 3-5 天内高度同质化——选物品、点格物、看数字。无里程碑、无阶段性奖励、无惊喜。 |
| **格物-技能深度** | 知识池消耗完全可预测（100/20=5次），规划变成除法题。固定 +20 无衰减无变异，消除了不确定性。 |

**核心问题**: 从重铸完成到下次重铸之间的 3-5 天是一个动机低谷。每晚格物的结果完全可预测（+20点/次），没有任何惊喜或中间奖励。Sylvester 明确警告：固定比率是最差的动机模型，玩家最容易在这段时间放弃。

**涉及文档**: 重铸与修复系统(动机强化-发现1,3)、格物与精魄系统(玩家体验-发现3, 技能深度-发现4)

### 共识 7: Trait系统与Tag系统概念重叠 + 价值计算双管线

| 视角 | 发现 |
|------|------|
| **标签-系统间交互** | FAKE(Trait) vs FAKE_HISTORY(Tag)、FLAW(Trait) vs BROKEN/DIRTY(Tag)、JACKPOT(Trait) vs IMPERIAL/CELEBRITY(Tag) 存在严重概念重叠。两套系统描述同一现实域但无映射规则。 |
| **标签-系统间交互** | 价值计算存在两条管线：Tag 乘积公式 vs 鉴定系统的 realValue/perceivedValue。修复/重铸后 realValue 如何同步？uncertainty 是否重置？ |
| **格物-数值一致性** | 格物"收窄~20%" vs 鉴定"x0.85衰减"，两者是否作用于同一 uncertainty 参数？修复/重铸后 uncertainty 行为未定义。 |

**核心问题**: 物品属性系统存在两套并行机制（Trait for 白天, Tag for 夜间），但它们描述的是同一个现实域。缺乏明确的边界定义和交互协议。价值计算也有两条管线，修复/重铸后的数值传导会产生不可预测的错误。

**涉及文档**: 物品变体与标签系统(系统间交互-发现1,2)、格物与精魄系统(数值一致性-发现9)

### 共识 8: 变体优先级自相矛盾

| 视角 | 发现 |
|------|------|
| **标签-数值一致性** | 文档优先级"重铸态>破损态"，但随后说"砸烂的御用怀表首先看起来是烂的"，自相矛盾。影响玩家对物品经济价值的感知。 |
| **标签-系统间交互** | 代码 priority 数值（重铸100+>破损50-99）与文档"破损覆盖重铸"意图相反。文档与实现未对齐。 |
| **标签-优雅性** | 关键设计决策尚未做出：IMPERIAL+BROKEN 共存时显示什么？两种优先级都有道理，但文档自相矛盾说明决策悬而未决。 |

**核心问题**: 一个看似简单的显示问题，但它直接影响玩家的决策质量——如果重铸后的御用怀表被砸烂了，玩家看到的是"$100 的破烂"还是"$10,000 的御用品"？三个视角都独立指出了这个矛盾，说明它在文档中确实是一个未解决的设计决策。

**涉及文档**: 物品变体与标签系统(数值一致性-发现13, 系统间交互-发现4, 优雅性-发现5)

### 共识 9: CURSED 标签无定义 -- 孤岛机制

| 视角 | 发现 |
|------|------|
| **标签-数值一致性** | CURSED 无价值系数、无获取/移除条件、无"厄运"具体定义。未定义的标签在实现时可能任意赋值，破坏平衡。 |
| **标签-系统间交互** | CURSED 在所有关联文档中均未提及具体机制。未定义玩法的标签不应出现在初稿枚举中。 |
| **标签-优雅性** | CURSED 不与任何现有系统互动，是"孤岛机制"。如果只是负面价值修正，则与 BROKEN 角色重叠。建议移除，等有完整设计时再加入。 |

**核心问题**: 三个视角一致建议从初稿中移除 CURSED 标签。它缺乏任何机制定义，不与任何系统互动，在当前版本中只会制造混乱。

**涉及文档**: 物品变体与标签系统(数值一致性-发现9, 系统间交互-发现12, 优雅性-发现7)

### 共识 10: 互斥性规则（格物vs重铸底材）缺乏量化和信息保护

| 视角 | 发现 |
|------|------|
| **标签-数值一致性** | 格物系统"残余知识要求"在变体标签文档中未被引用。重铸前置条件的数值阈值未定义。 |
| **重铸-数值一致性** | "完全榨干"判定标准不明确。顿悟=知识池归零=无法重铸？未格物物品是否可直接重铸？数值缺失。 |
| **格物-技能深度** | 玩家可能在"连击策略"中无意触发顿悟，导致底材永久失去重铸资格。构成 Sylvester "失败陷阱"。需要信息前置和操作确认保护。 |
| **格物-玩家体验** | 互斥规则的体验时机未设计。第一次违反时的挫败感可能很大。建议"渐进揭示"策略。 |

**核心问题**: "格物到底 vs 保留底材"是一个出色的博弈设计（三角化的典范），但缺乏两项保护：(1) 数值量化（阈值是多少？）；(2) 信息传达（玩家何时知道这个规则？如何避免无意触发？）。

**涉及文档**: 物品变体与标签系统(数值一致性-发现10)、重铸与修复系统(数值一致性-发现6)、格物与精魄系统(技能深度-发现10, 玩家体验-发现8)

## 二、标签系统独特发现

### T-1 🟡 G2材质标签与现有Category字段的冗余
**来源**: 标签-系统间交互 发现7
两者都试图回答"这件物品本质上是什么类型"。需明确 category（商品分类，面向展示）vs G2 Tag（材质属性，面向机制）的边界和映射关系。

### T-2 🟡 TRENDY(G2) 与 TRENDING(G3) 语义混淆
**来源**: 标签-系统间交互 发现8
两个几乎同义的标签分属不同组，玩家易混淆。建议重命名拉开语义距离（如 G2 改 POP_CULTURE，G3 改 HYPED）。

### T-3 🟡 TRENDING 标签时效性未定义
**来源**: 标签-数值一致性 发现11 + 重铸-数值一致性 发现13
价值暴涨系数、持续天数、衰减规则、触发条件全部空白。作为时间敏感标签，这些参数直接影响经济平衡和决策质量。

### T-4 🟡 MINT 标签可能是冗余设计
**来源**: 标签-优雅性 发现4
如果 MINT 只是"无负面标签"的同义词，则无存在必要。建议赋予独特价值修正（如 x1.2 溢价，格物后永久移除），使其成为"要不要拆封"的博弈点。

### T-5 🟡 G1 状态标签的互斥规则过于简单
**来源**: 标签-优雅性 发现3 + 标签-系统间交互 发现3
现实中物品可同时 BROKEN+DIRTY。可叠加设计增加修复决策层次（先清洁还是先修复？只清洁不修复？）。代码中 `tags[]` 数组无互斥约束。

### T-6 🟢 变体描述是"内容"而非"系统"，扩展成本高
**来源**: 标签-优雅性 发现6
每新增一个物品需手写 4 套变体文案。建议引入变体描述模板，80% 物品用"填表"代替"手写"。

### T-7 🟢 标签发现机制未整合到特征系统
**来源**: 标签-优雅性 发现8
标签的可见性（哪些一开始可见、哪些需发现）未定义。建议将标签发现嵌入已有的特征发现流程，零额外认知成本。

### T-8 🟢 修复后所有权"捡漏"边界未明确
**来源**: 标签-数值一致性 发现7
修复 BROKEN 恢复原价后等死当卖出，可能是有意的"捡漏"设计，但文档未明确说明。

### T-9 🟢 修复/重铸后 uncertainty 行为未定义
**来源**: 标签-数值一致性 发现8
修复后 uncertainty 保持？重铸后重置？直接影响精度收益和黑市波动。

## 三、重铸修复系统独特发现

### W-1 🔴 违约重铸的后果传达缺失 -- 可能是信息陷阱而非道德困境
**来源**: 重铸-决策质量 发现3
玩家在操作时能否预见"老兵回来->发现物品被改->仇恨结局"的因果链？如果不能预见，这是陷阱而非决策。需要操作时的风险预警和商人直觉提示。

### W-2 🔴 修复决策可能沦为"假决策"
**来源**: 重铸-决策质量 发现2
修复成本低+收益确定+无风险=永远修复。这是 Sylvester 信息过载/非决策。建议引入修复质量的弹性（低投入=部分修复 x0.7，高投入=完美修复 x1.0）。

### W-3 🟡 修复后赎回的反直觉激励
**来源**: 重铸-数值一致性 发现10
修复后归还只赚利息（$10），但等死当变现赚 $700。修复后玩家反而不希望客户赎回。与"消除利益对立"的设计目标矛盾。

### W-4 🟡 置换效应：修复的内在道德乐趣可能被外在资源消耗框架吞噬
**来源**: 重铸-动机强化 发现2
修复需要消耗积攒的点数，玩家思维从"要不要帮这个人？"（道德推理）转变为"30点匠心值不值？"（ROI计算）。建议修复只消耗精力（机会成本），不消耗预先积攒的精魄点数。

### W-5 🟡 违约惩罚延迟且不可预见 -- 玩家悔恨风险
**来源**: 重铸-动机强化 发现6
Day 8 重铸，Day 14 老兵才来。惩罚形式是"秋后算账"而非"即时后果"。"仇恨结局"的不可逆性可能导致玩家悔恨。建议渐进性惩罚+弥补机会。

### W-6 🟡 工作台操作完成后缺乏情感铺垫
**来源**: 重铸-动机强化 发现7 + 重铸-决策质量 发现10
修复/重铸完成后只有变体文字切换，没有"凝视时刻"或后果预览的情感铺垫。建议加入商人内心独白，激活"未来可能性"的感知。

### W-7 🟡 精魄产出类型与重铸消耗的匹配问题
**来源**: 重铸-数值一致性 发现9
库存中缺少特定 G2 标签物品时，某种精魄产出为零，重铸计划可能被无限推迟。建议引入跨类型转化（3:1损耗）或混合产出。

### W-8 🟡 修复与重铸的互斥/叠加关系不明确
**来源**: 重铸-决策质量 发现13
BROKEN 物品能否先修复再重铸？重铸能否在 BROKEN 状态直接进行？文档未定义，导致决策结构模糊。

### W-9 🟡 长期动机弧线 Day 15+ 塌陷风险
**来源**: 重铸-动机强化 发现5
重铸新鲜感在 2-3 次后急剧下降。需要配方复杂度递增、结果不确定性、叙事层递进来维持兴趣曲线的"Rising Peaks"。

### W-10 🟢 "底材"信息在白天收货时不可见
**来源**: 重铸-决策质量 发现5
玩家在白天议价时无法判断物品的工作台潜力。建议在鉴定界面显示"工作台潜力"简要提示。

### W-11 🟢 "不操作"缺乏显性价值
**来源**: 重铸-决策质量 发现11
如果修复和重铸永远有正收益，"不做"就不是合理选择。应明确"保留格物矿脉"的价值。

## 四、格物精魄系统独特发现

### G-1 🔴 格物无失败状态 -- 纯正面结果消除了风险维度
**来源**: 格物-技能深度 发现7
每次格物必然获得固定点数+必然收窄+概率特征。不存在"做得差"的可能。对比鉴定有 AP/耐心代价和反弹风险。建议引入低概率格物意外（走神5%/惊人发现5%/损伤2%）。

### G-2 🔴 顿悟缺乏仪式感呈现
**来源**: 格物-玩家体验 发现2
顿悟是格物系统的 Grand Finale，但当前只是 UI 文本变化。需要多感官呈现（视觉光晕+专属独白+仪式音效+消化时间）。

### G-3 🟡 "每件物品每晚只能格物1次"缺乏叙事包装
**来源**: 格物-玩家体验 发现4
规则机制合理但叙事突兀。建议提供理由（"需要沉淀消化"）和 UI 反馈（"沉淀中..."而非"今日已格物"）。

### G-4 🟡 三种精魄的视觉和获取手感同质化
**来源**: 格物-玩家体验 发现5 + 格物-技能深度 发现5
匠心/旧影/灵韵在概念上有丰富差异，但在操作中只是"+20 [类型名]"。建议差异化视觉语言（冷蓝/暖黄/淡紫）和获取特征（稳定/波动/递增）。

### G-5 🟡 格物与白天鉴定操作体验过于相似
**来源**: 格物-玩家体验 发现6
两者都是"点按钮->看数字变化+可能弹标签"。建议格物强调"沉浸式探索"（物品特写+慢节奏+沉思独白）vs 鉴定的"快速翻牌"。

### G-6 🟡 精力3点无成长弹性
**来源**: 格物-技能深度 发现6
Day 1 到 Day 30 夜间操作次数不变。随着消耗项增加（格物+修复+重铸+修行），精力压力递增但蛋糕不变大。建议有限成长（3->4->5，最多5）。

### G-7 🟡 新手首夜信息过载
**来源**: 格物-技能深度 发现8
第一晚同时面对：知识池、格物操作、三种精魄、两条消费轨道、进度继承、顿悟。建议渐进揭示（Night 1只格物+总量，Night 2-3解锁分类+修复，Night 4+解锁重铸/修行）。

### G-8 🟡 收益递减信息传达不足
**来源**: 格物-玩家体验 发现7 + 格物-技能深度 发现11
估价锁定后/特征全开后，玩家可能误以为"没什么可挖了"而提前放弃（错过顿悟暴击）。需"减项动画"和"距顿悟X次"提示。

### G-9 🟡 顿悟"全知全能"效果可能削弱后续决策空间
**来源**: 格物-技能深度 发现14
顿悟后物品处于完全信息状态，后续决策退化为计算题。建议保留微量不确定性（uncertainty 降至 0.05 而非 0）。

### G-10 🟡 顿悟暴击连击通胀风险
**来源**: 格物-数值一致性 发现7
3件"残血"物品可一晚触发 3 次顿悟，精力零消耗，产出 105 点 vs 正常 60 点。玩家会刻意"养残血"。是否有意为之需明确。

### G-11 🟡 精力前期浪费问题
**来源**: 格物-数值一致性 发现4
Day 1 可能只有 1 件物品，2/3 精力浪费。建议精力溢出结转或其他精力消耗渠道。

### G-12 🟢 故事解锁（Layer 4）缺乏内容规范
**来源**: 格物-玩家体验 发现10
物品故事的长度、格式、情感基调、与NPC关联方式未定义。建议标准格式（50-100字，聚焦一个情感瞬间）。

### G-13 🟢 精魄无上限积累的后期决策退化
**来源**: 格物-玩家体验 发现11
后期大量精魄积累使消耗成本无关紧要。考虑衰减机制或后期配方需精确三类配比。

### G-14 🟢 格物等级提升方向存疑
**来源**: 格物-数值一致性 发现10 + 格物-玩家体验 发现12
"每次格物消耗可能增加"如果是知识池消耗增加（加速），OK但需配套产出提升。如果是精力增加，是负面升级。建议明确为产出提升而非消耗增加。

## 五、设计亮点共识（保留强化）

以下亮点被多个视角独立识别和肯定：

### ⭐ "一个ID多种表现"架构 (3/9视角)
标签控制逻辑+变体控制显示的分层设计，用最小数据结构支撑丰富物品生命周期。

### ⭐ G1/G2/G3 三组标签分类 (3/9视角)
三组标签 1:1 映射三个子系统（修复/格物/重铸），构成"减-读-加"闭环。无角色重叠。

### ⭐ 乘法价值公式 (3/9视角)
一行公式覆盖所有物品状态的价值计算。"能写在餐巾纸上"的优雅标杆。

### ⭐ 所有权判定规则（修复=认可，重铸=灭失）(3/9视角)
一条二元规则产生深远的策略和道德后果。是涌现设计的种子。

### ⭐ 道德延迟设计 (3/9视角)
操作中性化，道德抉择推到后果环节。避免"Good/Evil选项"的简单化。

### ⭐ "垃圾库存变底材"的价值转化 (2/9视角)
BROKEN 物品从废品变原料，一个机制同时解决库存沮丧和材料来源。

### ⭐ 互斥性博弈（格物vs重铸底材）(3/9视角)
迫使在"榨干知识"和"保留底材"间取舍。经典三角化设计。

### ⭐ 顿悟三合一奖励 (3/9视角)
精力返还+点数暴击+全知解锁，三奖励满足三种动机。连击涌现策略是技能天花板典范。

### ⭐ 四层独立状态模型 (2/9视角)
估价/特征/知识池/故事四层独立可完成，赋予玩家定义"够了"的自主权。

### ⭐ 昼夜双轨经济节奏 (2/9视角)
白天现金（快/压力）vs 夜间点数（慢/策略），"吸气-呼气"的节奏互补。

## 七、总体评价

### 架构层面：出色

三个系统共同构成了一个完整的"价值循环链"——物品通过标签承载状态和本质，格物从中提取知识和精魄，工作台将精魄转化为修复/重铸操作回写标签。这个架构在理念上是优雅的：三组标签 x 乘法公式 x 变体映射的核心框架简洁有力，"一个ID多种表现"避免了内容爆炸，所有权判定规则一句话就产生了深远的策略和道德后果。

### 数值层面：危险

9 个视角中 5 个独立指出了重铸暴利率的根本性风险，4 个指出了消费端数值的全面缺失。当前文档中的示例数值（IMPERIAL x10.0, $50->$4,500）如果直接实现，将使重铸成为唯一最优策略，彻底架空典当交易这一游戏核心循环。这不是"后续可以调"的小问题——它影响的是三个系统共同构成的经济闭环的根基。必须在进入实现之前完成配方参数表和经济压力测试。

### 体验层面：需要补完

格物操作的交互深度不足以支撑"夜间核心玩法"的定位（4 个视角指出），3-5 天的精魄积累期存在动机真空（3 个视角指出），顿悟的仪式感呈现缺失。这些问题不影响系统的可行性，但直接决定了夜间玩法是"有趣的探索"还是"枯燥的日常作业"。

### 跨系统层面：需要对齐

Trait vs Tag 的概念重叠、价值计算的双管线、uncertainty 参数的跨系统行为——这些接口问题如果在实现前不明确，将在代码层面产生大量难以追溯的 bug。建议在 v1.1 迭代中专门增加"跨系统接口协议"章节。

### 当前核心风险

1. **经济崩溃风险**: IMPERIAL x10.0 + 缺乏消费参数 = 重铸印钞机，架空核心循环
2. **夜间无聊风险**: 格物操作深度不足 + 动机真空期 = 玩家在第二周开始跳过夜间
3. **信息错位风险**: Trait/Tag 双系统 + 价值双管线 = 实现时数值传导错误

### 建议迭代优先级

**第一轮 (v1.1 / 下调经济+补数值)**:
- P0 #1-5: 解决经济模型根本问题
- P1 #8-10: 清理已知矛盾和无效标签

**第二轮 (v1.2 / 强化体验)**:
- P1 #6-7, #14-16: 提升格物交互深度和动机设计
- P1 #11-13: 完善决策质量和信息传达

**第三轮 (v1.3 / 精细打磨)**:
- P2 全部: 视觉差异化、边缘场景、长期平衡
