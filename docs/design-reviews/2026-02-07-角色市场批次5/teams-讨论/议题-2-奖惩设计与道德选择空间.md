# Teams 跨系统讨论综合报告 — 议题2

> **日期**: 2026-02-08
> **议题**: 暗路/混合路线的奖惩设计如何影响玩家的道德选择空间？
> **涉及文档**: 人物能力升级系统 v1.3 + 黑市系统 v3.5 + 经济参数 v1.1
> **参与成员**: player-psychologist, systems-balancer, narrative-integrator
> **讨论方式**: Teams 架构（TeamCreate → 三成员并行初始评审 → SendMessage 交叉讨论 → 广播聚焦讨论 → 收集共识）

## 六项共识（含1项从分歧升级）

### 共识 1: 代价信号必须与奖励信号同步——叙事主体+微弱数值锚点
- **结论**: 每次暗路操作的即时反馈中同时包含奖励信号和代价信号。代价信号以叙事为主体（商人独白、NPC反应），微弱数值影响为辅助锚点（"额外谨慎客户"机制）
- **约束**: 清白30以上区间经济影响<暗路技能加成的1/3（即<日利润10-12%）；暗路始终净正收益（浮士德交易前提）
- **理由**:
  - player-psychologist: 双曲折扣导致延迟代价心理上被折扣为零。代价必须与奖励同步出现。叙事代价避免"外在惩罚置换内在罪疚"的Displacement Effect
  - systems-balancer: 暗路30天全程净正收益（蜜月期+$560/天，惩罚期仍+$340~540/天），延迟惩罚经济力量不足。微弱数值是"注意力触发器"
  - narrative-integrator: 当前结构是"温水煮青蛙"，核心愿景需要"浮士德交易"——经济上永远划算，道德上永远有代价

### 共识 2: 阈值惩罚转为渐进信号的累积质变——"由内而外"弧线
- **结论**: 保留清白<30和<15的阈值效果，但在清白50-30区间引入渐进信号。叙事按"由内而外"弧线组织，每层瞄准不同心理触发器
- **"镜子法则"三层叙事预警**（player-psychologist 提出，三方认可）:

  | 层级 | 清白区间 | 叙事表达 | 心理作用 |
  |------|---------|---------|---------|
  | 内在镜子 | 50-40 | 商人独白变化 | 自我监控："我做了什么" |
  | 社会镜子 | 40-35 | 新闻/邮件/社会信号 | 社会压力感知："别人看到了" |
  | 关系镜子 | 35-30 | NPC行为变化/谨慎客户 | 身份认知质变："我变成了什么" |

- **数值伴随**: 额外谨慎客户在某清白阈值开始低概率出现（起始点[待数值验证]），概率渐增至清白30时~35-40%
- **约束**: 相邻惩罚阈值间至少5点清白间距（hedonic adaptation适应期，player-psychologist）

### 共识 3: 混合路线需独有身份和两层补偿——"通达：灰色地带的生存者"
- **结论**: 混合路线有独有的身份叙事和机制补偿，总效率目标为极端路线的85-90%
- **两层补偿结构**:
  - **底层（数值）**: 三系精魄均>50时格物效率+15%，缩小发展延迟从7天到3-4天
  - **表层（正交）**: 混合路线独有被动——次日首客洞察/鉴定AP-1（"阅人无数的直觉"）
- **叙事身份**: 连续5天混合经营→矛盾并置独白+"灰色地带的生存者"标签。因果自见对混合玩家显示更模糊的闪现（"你看不清前方的路。也许这本身就是答案。"）
- **三重结构性歧视量化**（systems-balancer）: 精魄差距(-20%) + 声誉调制弱(-20%) + 精通缺失 = 总效能差距40%+。7天发展延迟在30天游戏中是严重的结构性惩罚
- **身份认同需求**（player-psychologist）: 身份认同不能用数值购买（Rouse Fantasy动机），"通达"应是积极身份"读懂每一个人"
- **叙事定位**（narrative-integrator）: 混合路线的身份是"质疑身份本身"——矛盾并置独白、自我质疑独白

### 共识 4: 施压/攻心不加即时清白代价，道德承重墙=合同档位
- **结论**: 施压和攻心在道德性质上有区分（施压=专业施压，攻心=心理操控），区分通过叙事层体现（NPC反应强度、商人独白内容），但不引入额外数值代价差异。合同档位选择才是道德选择的关键节点
- **理由**:
  - player-psychologist: 攻心对DESPERATE目标使用前增加商人独白确认提示（非系统弹窗），增加情感重量
  - systems-balancer: 施压/攻心使用频率可能导致清白值下降过快，压缩暗路有效游戏时间
  - narrative-integrator: "游戏不判断道德"意味着不应在机制层区分两者的道德代价

### 共识 5: 清白轴交错排列两系统代价
- **结论**: 人物能力系统和黑市系统的负面后果在清白轴上交替触发，不同时叠加
- **交错排列方案**（systems-balancer 提出，三方认可）:

  | 清白区间 | 能力系统 | 黑市系统 | 叙事统一点 |
  |---------|---------|---------|----------|
  | 50-40 | 商人独白微变 | 联系人对话微变 | "你在改变" |
  | 40-30 | NPC偶尔犹豫 + 新闻/邮件 | 佣金"熟客"档 | "别人注意到了" |
  | 30-20 | 客源萎缩-1 | 灰色客户增加 | "你的世界在改变" |
  | 20-0 | 执法关注概率 | 危险任务 + 免佣金 | "你已深陷其中" |

- **约束**: 相邻阈值间至少5点清白间距；两系统数值效果不简单叠加

### 共识 6: "通达"双触发路径（从分歧升级）
- **结论**: "通达"有两个独立触发路径（OR关系），分别对应长期身份确认和短期行为奖励
  - **长期触发**: 三系精魄均>50 → 格物效率+15%（身份确认："你是混合玩家"）
  - **短期触发**: 当天2+种合同档位 → 次日首客AP-1（行为奖励："今天你又做了混合选择"）
- **来源**: 原为分歧3（触发条件），systems-balancer 提出OR关系，三方同意升级为共识

## 分歧（2项，需裁决）

### 分歧 1: 额外谨慎客户起始清白值
- **player-psychologist**: 40——清白50-40应是"纯叙事期"，给玩家10点清白的"纯感受期"
- **systems-balancer**: 45——早期微弱信号（15%概率，-3%利润）几乎不影响经济但提供叙事锚点
- **narrative-integrator**: 45——与systems-balancer一致
- **标记**: [待数值验证]——需要playtest确认节奏感。player-psychologist可接受上调到45

### 分歧 2: 明察秋毫/FLAW杠杆是否引入风险机制
- **player-psychologist**: 引入程度偏差（高估FLAW严重性，非性质偏差），误判率与声誉调制挂钩
- **systems-balancer**: 被动技能无误判——明察秋毫依赖鉴定确认FLAW后才触发，不应有误判
- **narrative-integrator**: 撤回原始"半主动化+bluff风险"提案，接受systems-balancer立场。建议如引入风险，应在"杠杆使用环节"（选择强调哪个FLAW）而非技能本身
- **标记**: [待设计]——复杂度超出当前议题范围

- **原始分歧**: 三系精魄>50(systems-balancer) vs 当天2+种合同档位(player-psychologist) vs 调制下限提升(narrative-integrator)

### Direction A价值归零

## 融合方案

### 方案 1: "道德回声"系统——即时代价信号的统一调度框架
- **描述**: 跨人物能力系统和黑市系统的统一代价信号层。每次暗路操作触发微弱的"道德回声"——利用现有叙事通道（商人直觉、新闻、邮件、NPC对话）的统一调度

  | 触发行为 | 即时回声（当天） | 延迟回声（次日） |
  |---------|----------------|----------------|
  | 施压 | 商人独白尾句变化 | 无 |
  | 攻心（对DESPERATE） | 商人独白 + NPC反应强化 | 次日新闻概率出现社区议论 |
  | 高利贷档成交 | 商人独白变化 | 次日邮件概率出现匿名警告 |
  | 黑市主动出售 | 联系人评论 | 无 |
  | 赃物交易 | 联系人评论 + 热度变化 | 次日新闻概率出现盗窃报道 |

- **涉及系统**: 商人直觉、新闻系统、邮件系统、NPC对话系统
- **来源**: player-psychologist"代价信号同步" + narrative-integrator"三层道德镜子" + systems-balancer"不改变经济模型"

### 方案 2: "渐进式清白衰减"——阈值惩罚的前奏信号
- **描述**: 清白50-30区间引入连续微弱数值影响。"额外谨慎客户"概率渐增，始终不足以改变暗路经济可行性

  ```
  "额外谨慎"客户出现概率 = f(清白值)
  清白 >= 起始点: 0%（无影响）
  起始点-5:       15%（偶尔一个更难谈的客户）
  起始点-10:      25%
  起始点-15:      35%
  清白30:         40%（阈值前最大）

  效果: 该客户初始耐心-1 或 推拉风格升级为HARD
  经济影响: -3%到-12%（暗路技能加成的1/3以内）
  ```

- **涉及系统**: 客户生成系统、议价系统
- **来源**: systems-balancer"微弱数值锚点" + player-psychologist"渐进>阈值" + narrative-integrator"微弱数值是叙事的机制证据"

### 方案 3: "通达"混合路线身份系统
- **描述**: 两层补偿 + 叙事身份 + 双触发路径

  **底层（长期触发）**: 三系精魄均>50时格物产出+15%（"见多识广的理解力"）

  **表层（短期触发）**: 当天2+种合同档位 → 次日首客洞察/鉴定AP-1（"阅人无数的直觉"）

  **叙事身份**:
  - 连续5天混合经营 → 矛盾并置独白 + "灰色地带的生存者"标签
  - 因果自见显示模糊闪现（vs 极端路线的清晰预兆）
  - 商人独白更多体现自我质疑："你不知道自己是好人还是坏人。也许两者都不是。"

- **涉及系统**: 人物能力系统、商人直觉、修行面板
- **来源**: 三方共识3+共识6

### 方案 4: 黑市-能力系统道德弧线统一
- **描述**: 两系统代价在清白轴上交错排列，配合"由内而外"叙事弧线，确保渐进堕落而非多系统同步崩溃
- **涉及系统**: 人物能力系统、黑市系统、声誉系统
- **来源**: 共识5

## 补充洞见（讨论中涌现）

- **FLAW杠杆半主动化+bluff系统**（narrative-integrator 提出，systems-balancer 验证）: 将明察秋毫从纯被动改为半主动——鉴定确认FLAW后安全激活（-3%，无风险），未鉴定直接bluff有信任崩溃风险（耐心-2，效果减半）。这解决了"Direction A归零"问题，让鉴定对暗路玩家重新有价值——从"看更准"变为"bluff前先确认"的风险消除工具。FLAW出现率35-45%时策略三角最有趣。标记为[议题2延伸-待后续设计]
