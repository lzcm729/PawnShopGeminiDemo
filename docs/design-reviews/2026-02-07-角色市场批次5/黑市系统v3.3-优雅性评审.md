# 黑市系统 v3.3 — 优雅性与涌现性评审

> **评审日期**: 2026-02-07
> **评审对象**: `黑市系统 (Black Market System).md` v3.3
> **评审视角**: 优雅性与涌现性 (Elegance & Emergence)
> **评审依据**: Tynan Sylvester 优雅启发 (Smelling Elegance Heuristics)
> **关联文档**: 典当业务系统 v1.6、新闻与传闻系统 v1.1、鉴定系统 v1.7、经济参数 v1.1

---

## 发现列表

### 1. ⭐ 双轨制是一个优雅的核心架构

**问题**：无，这是亮点。

**分析**：双轨制（黑市收购 vs 玩家出售）用一个极其简单的区分——"谁主动"——创造了丰富的决策空间。这符合 Sylvester 优雅启发 #2（简单到能写在餐巾纸上）：

> "高价但不确定（等黑市要） vs 低价但确定（你主动卖）"

一句话就能概括整个系统的核心张力。更重要的是，这个简单区分与资金压力系统（医药费倒计时）形成了经典的乘法关系（启发 #1）——资金充裕时等待是理性的，资金紧张时低价抛售是被迫的。这不是两个独立机制的简单加法，而是二者相互放大了对方的情感力量。

**建议**：保持不变。双轨制是整个黑市系统的优雅骨架。

---

### 2. ⭐ uncertainty 与黑市波动的联动（方向 C'）

**问题**：无，这是亮点。

**分析**：v3.3 新增的鉴定精度波动机制是一个教科书级的"与多个系统互动"设计（启发 #1）。一个变量（uncertainty）同时影响：
- 议价阶段的开价和侮辱阈值（方向 A）
- 推拉过程中的让步幅度（方向 D）
- 黑市出售的价格波动幅度（方向 C'）
- 黑市收购的精度修正（方向 C'）

而且它复用了鉴定系统已经建立的连续函数模型，没有引入新概念（启发 #5）。玩家不需要学习新规则——"鉴定越仔细，卖价越稳定"是直觉可理解的。

**建议**：保持不变。这是跨系统优雅联动的优秀范例。

---

### 3. 🟡 佣金模型的五档阶梯认知负担偏高

**问题**：佣金模型设计了 5 个离散阶梯（20%/15%/10%/5%/0%），每档对应 20 点声誉区间。玩家需要记忆五档费率及其对应的声誉阈值。

**分析**：对比 uncertainty 的连续函数设计，佣金模型采用了离散分级。这本身不是问题——离散分级在某些场景下比连续函数更易感知（"我从熟客升到了老主顾"比"我的佣金系数从 0.12 降到了 0.07"更有叙事感）。

但五档的问题在于：中间三档（15%/10%/5%）的差距感不明显（每档只差 5 个百分点），而且 20 点声誉区间在游戏进程中的跨越速度不清楚。如果声誉积累很慢，玩家会长期停留在某一档，感知不到进步；如果很快，五档就变成了走过场。

从优雅启发 #6（规模相似）来看，5% 的佣金差在低价值物品上几乎感知不到（$500 物品差 $25），只在高价值物品上才有意义。

**建议**：考虑简化为三档（新人 20% / 熟客 10% / 自己人 0%），阈值改为 0-39 / 40-69 / 70+。每次升级的佣金变化更显著（10 个百分点），感知更清晰。中间档可以通过升级系统的收购价加成来补充梯度感。如果坚持五档，建议让 UI 明确显示"下一档需要 XX 声誉"和"当前佣金节省了 $XX"，降低认知负担。

### 4. 🟡 热度系统与佣金系统的角色重叠

**问题**：热度和佣金都是"使用黑市的代价"，二者在功能上存在部分重叠（启发 #4：机制不应重叠角色）。

**分析**：仔细分析后，这两个系统确实服务于不同的决策维度：
- **佣金**：长期代价，反映与黑市的关系深度，影响经济效率
- **热度**：短期代价，反映当前风险水平，影响是否继续交易

但在玩家感知层面，二者都回答同一个问题："我该不该用黑市？"当两个系统同时给出"不建议"的信号时（高佣金 + 高热度），它们没有乘法互动，只是简单叠加了惩罚。而当二者信号矛盾时（低佣金但高热度，或高佣金但低热度），才会产生有趣的决策。

问题在于：声誉增长是单调的（只增不减，除了特定事件），而热度是波动的（每日衰减 + 交易累加）。这意味着随着游戏推进，佣金永远在变好，热度是唯一真正的制约因素。佣金最终会衰减为零摩擦，失去约束力。

**建议**：目前的设计在结构上是可行的，因为高 Underworld 声誉（=低佣金）会触发负面后果（保护费、警方关注等），这在一定程度上平衡了佣金消失的问题。但建议更明确地将佣金定位为"进入成本"（入门期摩擦），将热度定位为"使用成本"（持续摩擦），并在 UI 和叙事上区分这两种摩擦，避免玩家感到"被双重惩罚"。

### 5. 🔴 高 Underworld 负面后果是四个独立机制，认知负担严重

**问题**：第 6 节定义了四种负面后果：保护费、危险任务、客户生态变化、警方重点关注。每种有独立的触发阈值、频率、效果。这违反了优雅启发 #2（简单机制）和 #4（不重叠角色）。

**分析**：从 Sylvester 的优雅框架来看，这四个机制的"价格标签"很高——玩家需要理解四套独立规则——但产生的体验种类可能不够丰富来证明这个成本。

逐一分析：
- **保护费**：周期性经济压力。与医药费在机制角色上重叠（都是"每隔一段时间必须付钱"）。
- **危险任务**：叙事事件。独特，有涌现潜力（存放可疑物品后被搜查），但 10%/天的概率意味着可能很多天不触发，也可能连续触发，体验不稳定。
- **客户生态变化**：改变来客构成。有涌现潜力（更多赃物 = 更高热度 = 更多风险事件），但作为"持续"效果，玩家难以感知到具体变化——"是因为我 Underworld 高了还是随机波动？"
- **警方关注**：提高热度事件概率。与热度系统本身高度重叠（热度已经是一个概率机制，在概率机制上叠加概率修正，玩家根本感知不到 +5% 的概率差异）。

四个机制中，只有"危险任务"具有真正独特的角色（叙事驱动的选择），其他三个在功能上存在不同程度的重叠或感知问题。

**建议**：精简为两个核心负面后果：

1. **保护费/勒索**（合并保护费 + 危险任务）：周期性事件，随声誉等级升级——低声誉时是简单的收保护费（经济代价），高声誉时变成要求帮忙（叙事+风险代价）。这是同一个机制的难度曲线，而非两个独立机制。

2. **客户生态漂移**（合并客户生态变化 + 警方关注）：高 Underworld 吸引更多灰色客户，灰色客户天然带来更多赃物交易和更高热度。不需要单独的"+5% 概率"修正——更多赃物交易本身就会推高热度，进而增加风险事件概率。让系统自然涌现，而非手动叠加修正系数。

这样从四个机制变为两个，认知负担减半，但涌现空间不减反增——因为第二个机制创造了一个自我强化的反馈循环：高声誉 -> 更多灰色客户 -> 更多赃物 -> 更高热度 -> 更多风险事件。

### 6. 🟡 收购标签系统的涌现性受限于"纯随机"

**问题**：2.1 节说明收购标签是"纯随机，每个标签等概率"。这缺少与其他系统的互动（启发 #1），限制了涌现潜力。

**分析**：当前设计中，新闻系统可以暗示收购方向（"投资者关注贵金属"→ 次日 70% 概率收购 [贵金属]），这是好的。但标签本身的生成是纯随机的，这意味着：

1. 玩家无法通过任何行为影响收购标签的出现——只能被动等待。
2. 收购标签与声誉、热度、升级等级都没有交互——这些参数只影响价格和额度，不影响"买什么"。
3. 新闻暗示是唯一的预测手段，但也只是概率修正。

这使得"策略囤货"（场景一）在很大程度上依赖运气而非技能。玩家能做的最优策略就是"持有多个品类的物品"来分散风险——这是一个一次性的策略发现，没有持续的决策深度。

**建议**：考虑让收购标签的生成受到轻微的系统性偏置影响，例如：
- 连续 3 天未出现的标签概率轻微提高（伪随机保底，类似 FAKE 特征的设计）
- 新闻暗示后未必次日出现，但 3 天内出现概率累计提高（延长决策窗口）
- 升级系统 Lv3+ "情报网络" 可以在前一晚预览次日收购标签（不改变结果，但提供信息优势）

其中第三点特别有价值——它让升级系统的功能从"数值加成"扩展到"信息优势"，与鉴定系统的核心主题（"信息就是金钱"）形成呼应。

### 7. ⭐ 差异化热度是简单且多用途的优雅设计

**问题**：无，这是亮点。

**分析**：收购 +1 / 出售 +2 / 赃物额外 +1 的热度规则，简单到可以写在三行里（启发 #2），却产生了丰富的策略权衡：
- 等收购不仅价格高，风险也低——双重奖励"耐心"
- 急售不仅价格低，风险也高——双重惩罚"急躁"
- 赃物交易总是额外危险——强化道德选择

这三条规则之间有乘法关系：急售赃物（+3）是最危险的行为，同时也是最亏钱的行为。惩罚完美对齐了玩家的内在直觉（"干坏事又着急，当然更危险"）。这符合 Sylvester 的"奖励对齐"原则。

**建议**：保持不变。

---

### 8. 🟡 升级系统的三个参数维度中，"收购限额"的涌现性最弱

**问题**：升级系统提供三个维度的提升——收购限额（3->8）、热度衰减（-1->-3）、收购价加成（0%->10%）。其中收购限额只是一个数量阈值，几乎不与其他系统互动。

**分析**：从优雅启发 #1（与多个系统互动）来看：
- **热度衰减**：与热度系统直接互动，间接影响风险事件触发概率，影响交易频率策略。优雅。
- **收购价加成**：与佣金模型、鉴定精度（uncertainty）叠加互动，影响最终收入。优雅。
- **收购限额**：只影响"每天能卖几件"，不与其他任何系统互动。它是一个硬上限，不产生有趣的决策——在达到上限前无影响，达到上限后直接截断。

收购限额从 3 提升到 8，在实际游戏中可能很少成为瓶颈。考虑到每日客户最多 4 人，库存积累速度有限，3 件/天的限额可能已经足够覆盖大部分情况。如果限额很少成为实际约束，那么为它升级就没有感知到的价值。

**建议**：考虑将"收购限额"替换为更有互动性的升级维度，例如：
- **品类扩展**：低等级只能收购基础品类（电子、贵金属），高等级解锁稀有品类（古董、艺术品），让升级影响"买什么"而非"买多少"
- **信息优势**：高等级时提前获知次日收购标签（如发现 6 中的建议），让升级影响决策质量

或者保留限额但将其与收购标签生成合并——Lv1 每日 1-2 个标签各限 1 件，Lv5 每日 3-4 个标签各限 2 件——让限额通过标签多样性体现，而非单纯的数量上限。

### 9. 🟢 流当结算联动是优雅的系统复用

**问题**：无，这是值得肯定的简化。

**分析**：v3.3 将流当结算改为"按当天黑市出售价卖出"，而非单独设计流当变现机制。这完美体现了 Sylvester 的优雅启发 #3（可多用途使用）和 #5（复用已建立的惯例）：同一个价格公式同时服务于"主动出售"和"流当结算"两个场景，玩家学一次规则就能理解两个场景。

同时，因为黑市价格受 uncertainty 波动影响，流当结算自然也继承了"鉴定精度影响变现收益"的逻辑——不需要额外的 `uncertaintyAtDeal` 变量或流当偏差公式。一个变量的移除换来了更少的特殊情况和更一致的玩家心智模型。

**建议**：保持不变。

### 10. 🟡 风险事件的三级结构在体验梯度上有断层

**问题**：三种风险事件（便衣暗访、搜查警告、正式调查）在严重度上存在不均匀的梯度跳跃。

**分析**：

| 事件 | 经济代价 | 时间代价 | 声誉代价 |
|------|---------|---------|---------|
| 便衣暗访 | 0 | 当晚关闭 | 0 |
| 搜查警告 | $300-500 或 0 | 0 或 3 天 | 0 |
| 正式调查 | 0 | 7 天 | 商誉 -10 |

从优雅性角度看：
- 便衣暗访太轻（只损失当晚剩余交易机会），可能不构成实际威慑
- 搜查警告有选择（二选一），这是好的设计——给玩家能动性
- 正式调查跳到商誉 -10 + 7 天锁定，与前两级的差距过大

梯度跳跃的问题在于：玩家在"关注"热度（15% 概率触发便衣暗访）时几乎不在意，因为后果太轻；到"危险"热度（50% 概率触发正式调查）时又突然面临灾难性后果。中间缺少"逐渐加重的压力感"。

**建议**：让便衣暗访稍有"牙齿"——例如当晚关闭 + 次日出售价下浮 5%（"买家们也听到风声了"）。这与新闻系统联动（启发 #1），也让"关注"热度不再是可以安全忽略的等级。或者更简单：便衣暗访触发后热度不衰减（"有人盯着你了"），使其成为一个延迟炸弹而非一次性事件。

### 11. 🔴 声誉轴命名不一致：Underworld vs Innocence (清白)

**问题**：黑市系统全文使用 "Underworld 声誉" 作为第三声誉轴名称，但经济参数 v1.1 已将其更新为 "Innocence (清白)"。系统内部逻辑与命名相矛盾。

**分析**：经济参数 v1.1 的版本历史明确记录了 "声誉轴'黑道'到'清白'" 的变更。但黑市系统 v3.3（同一天更新）仍然使用旧名 "Underworld"。

这不仅是命名问题，还影响设计逻辑的方向性：
- "Underworld 声誉"是**正向计数**——越高越深入黑道，需要 60+ 触发负面后果
- "Innocence (清白)"是**反向计数**——越高越清白，做坏事会减少

如果第三轴确实改名为"清白"，那么本文档第 3 节的佣金阶梯、第 6 节的负面后果触发阈值需要全部反转（例如"清白 <= 40 触发保护费"而非"Underworld >= 60"）。

这是一个 P0 级的一致性问题——如果两个文档对同一个轴的计数方向相反，实现时必然出错。

**建议**：立即统一命名和计数方向。无论最终选择 "Underworld（正计数）" 还是 "Innocence（反计数）"，都必须在黑市系统和经济参数文档中保持一致。考虑到黑市系统的叙事语言（"与黑暗面共舞"、"自己人"等）更适合正向的 Underworld 概念，但经济参数已经做出了改动，需要设计师做出明确的最终决策。

### 12. 🟢 DSL 扩展设计的预见性

**问题**：无，这是值得肯定的设计。

**分析**：第 10 节的 DSL 扩展需求为未来内容创作预留了清晰的接口，包括违约反应、新闻联动、收购暗示、保护费和危险任务。这体现了数据驱动开发理念——机制由代码实现，内容由 DSL 定义，策划可以独立扩展事件种类和叙事。

从优雅性角度看，DSL 是"机制复用多次"（启发 #7）的基础设施——同一套事件触发和选择机制可以承载无限的叙事内容。

**建议**：保持不变。

### 13. 🟡 出售系数的波动因素过多，难以形成玩家心智模型

**问题**：2.2 节定义了四个影响出售价的波动因素——基础随机（0.65-0.80）、品类行情（+/-5%）、新闻联动（+/-5%）、鉴定精度波动。再加上佣金扣减。最终价格是五个因素的复合结果。

**分析**：从优雅启发 #2（简单）来看，当玩家在黑市面板上看到一件物品的出售价 $720 时，他无法判断这个价格"好不好"——它可能是基础随机偏高 + 品类行情偏低 + 新闻无影响 + 精度波动略偏 + 佣金 10% 的结果。太多因素叠加使得玩家无法建立"$720 是好价还是坏价"的直觉。

对比黑市收购的价格公式——"真实价值 x 收购系数 x 升级加成 x 佣金 x 精度修正"——虽然因素也不少，但收购系数是当日可见的（如 125%），玩家容易建立基准。出售价则缺少这样的"锚点"。

**建议**：考虑在 UI 中提供一个简化的"今日行情"指示器（例如"出售行情：偏低 / 正常 / 偏高"），让玩家在不理解全部公式的情况下也能做出"今天卖还是等明天"的决策。这不改变底层计算，只改变信息呈现方式。或者更激进地简化：将品类行情和新闻联动合并为一个"市场情绪"修正（+/-5%），减少独立变量数量。

### 14. 🟢 2.3 节对比表清晰展示了双轨差异

**问题**：无，这是文档层面的亮点。

## 亮点

## 总体评价

黑市系统 v3.3 的核心架构（双轨制 + 热度 + uncertainty 联动）展现了出色的优雅性。简单的规则之间产生了丰富的乘法互动——资金压力放大了双轨选择的痛苦，鉴定精度影响了卖出价的可预测性，热度创造了"贪心的代价"。这些都是 Sylvester 所说的"简单、工匠式的设计在游戏中绽放成千百种体验"的典范。

主要的优雅性瓶颈集中在两个区域：**高 Underworld 负面后果**和**价格因素叠加**。前者用四个独立机制做了可以用两个机制完成的事情（违反启发 #4 角色不重叠），后者让出售价的可预测性降低到玩家难以建立心智模型的程度。声誉轴命名不一致（Underworld vs Innocence）是必须立即解决的 P0 问题，否则后续实现将面临方向性错误。

建议的优化方向是"减法"而非"加法"——精简负面后果为两个核心机制、简化佣金为三档、为出售价提供直觉锚点。优雅设计的本质是"去除多余的大理石找到雕像"，这个系统的骨架已经很好，需要的是打磨而非添加。
