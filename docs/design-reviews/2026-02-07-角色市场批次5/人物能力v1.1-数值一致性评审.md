## 发现列表

### 1. 🟡 日均精魄产出 ~60 仍为假设值，缺乏上游文档支撑

**问题**: 文档第 5.2 节声明"日均精魄产出 ~60 点（三系合计，含道德加成）"，并注明"精魄实际产出由格物系统定义（每晚精力 x 每次汲取产出）"。但格物与精魄系统文档 v1.0 仅给出了每次汲取 20 点和每晚精力 3 点（基础值），推算日均产出 = 3 x 20 = 60，这是不含道德加成的裸值。

**分析**:
- 格物系统第 9.3 节：每次格物消耗 20 点知识池，产出 20 点精魄（一比一）
- 夜间精力基础值 3 点（昼夜循环文档）
- 精密工作台升级可 +1~3 精力（店铺升级系统）
- 因此实际日产出范围为：
  - **早期（无升级）**: 3 x 20 = 60 点
  - **中期（+1~2 精力）**: 80~100 点
  - **后期（+3 精力）**: 120 点
- 文档写的 ~60 是早期基准，但全部 12 技能需要 990 点，计算"16.5 天全解锁"用的是 60 点/天，**这忽略了精力需要在格物/修复/重铸/修行四者间竞争分配**
- 实际修行可用精力可能只有 1 点/天（假设 3 精力中 2 点用于格物），那么日均修行用精魄为 20 点——全解锁需要 ~50 天，远超 30 天游戏周期

**建议**:
1. 明确区分"日均产出精魄"和"日均可用于修行的精魄"两个概念
2. 在经济参数文档中增加精魄经济章节，定义精力分配模型
3. 重新计算 30 天实际可解锁数量——考虑精力还要分给格物/修复/重铸，日均"净可投入修行"的精魄可能只有 20~30 点

### 2. 🔴 修行消耗 1 夜间精力的隐性成本远超精魄成本

**问题**: 每个技能学习消耗"精魄 + 1 夜间精力"。但文档的成本分析（第 5.3 节）只计算了精魄成本（50/100 点），完全未考虑精力的机会成本。

**分析**:
- 1 点夜间精力 = 1 次格物 = 产出 20 点精魄
- 如果物品接近顿悟（知识池 <=20），1 点精力还能触发顿悟奖励：精力返还 + 额外 20% 知识池点数 + 全知全能
- 对于知识池 100 的普通物品，顿悟额外奖励 20 点，加上本次汲取 20 点 + 精力返还 = 实际收益 40 点精魄 + 真值锁定 + 特征全开 + 故事解锁
- 因此 1 点精力的机会成本在 20~40+ 点精魄之间，取中位数约 25 点
- T1 技能实际总成本 = 50 精魄 + ~25 精魄机会成本 = **~75 精魄等价**
- T2 技能实际总成本 = 100 精魄 + ~25 精魄机会成本 = **~125 精魄等价**
- 12 技能总计消耗 12 点精力 = 12 次格物的机会成本 = **~300 精魄等价**

这意味着 12 技能的真实总成本不是 990 点，而是 **~1290 点等价精魄**。技能成本实际比文档描述的高出约 30%。

**建议**:
1. 在第 5.3 节的投资竞争表中增加"含精力机会成本"列
2. 确认这个隐性成本是否属于有意设计（如果是，应该在文档中明确承认并分析其对玩家决策的影响）
3. 这个隐性成本实际上**强化了**"变强 vs 赚钱"的核心矛盾，是好的设计——但需要被文档化

### 3. 🟡 道德精魄加成的非对称性：慈善 vs 高利贷 vs 标准

**问题**: 第 7 节道德精魄加成表显示慈善(+4)和高利贷(+4)的加成相同，但标准(+2)只有一半。

**分析**:
- 以日均 4-5 笔交易计算：
  - 全慈善：灵韵 +16~20/天（占 60 基础的 27-33%）
  - 全标准：匠心 +8~10/天（占 60 基础的 13-17%）
  - 全高利贷：旧影 +16~20/天（占 60 基础的 27-33%）
- **标准路线获得的加成仅为极端路线的一半**
- 标准路线（商誉导向/匠心系）是"做本分生意"的中间路线，但在精魄经济中被惩罚为最慢的成长路径
- 纯匠心路线（察隐 50 + 破妄 100 = 150 匠心）：
  - 全标准：日均匠心 8~10，占比不错但是...标准档只给匠心 +2，而非 +4
  - 回本天数：150 / (20 + 8) = ~5.4 天（含加成）vs 150 / 20 = 7.5 天（不含加成），加速约 28%
  - 对比全慈善灵韵路线：150 / (20 + 16) = ~4.2 天，加速约 44%
- 这个差异是否有意设计？文档未说明"为什么走中间路线的玩家成长更慢"

**建议**:
1. 如果有意为之（鼓励走极端），应在文档中明确说明设计意图
2. 如果无意，考虑标准档提升至 +3 匠心，缩小差距（慈善/高利贷仍保持 +4 的极端路线优势，但标准路线不至于被甩开太远）
3. 注意：收购赃物只给旧影 +2 而非 +4，这与高利贷的 +4 不对称也需要理由

### 4. 🟡 精通奖励的经济价值分析——旧影精通可能过强

**问题**: 第 9 节精通奖励中，旧影精通"施压/攻心不消耗耐心"的经济价值显著高于其他两条。

**分析**:

| 精通路径 | 奖励 | 解锁成本 | 经济价值 |
|---------|------|---------|---------|
| 匠心精通 | 鉴定 AP-1（最低 1） | 150 匠心 | 每次鉴定省 1AP，按日均 4-6 次鉴定 = 省 4-6 AP/天 |
| 旧影精通 | 施压/攻心不消耗耐心 | 150 旧影 | 攻心本身已不消耗耐心；施压基础消耗 1 耐心变为 0，实际仅省 1 耐心/议价 |
| 灵韵精通 | 抚慰额外 +3 hope（总 +8） | 150 灵韵 | 纯叙事/道德价值，无直接经济收益 |

等等——重新审视：旧影精通是"施压/攻心**不消耗耐心**"。但攻心在 v1.1 第 4.2 节已经是"不消耗耐心"了。如果精通奖励让施压也不消耗耐心，那么精通奖励实际价值仅为"施压不消耗耐心"。

- 施压消耗 1 耐心，精通后变为 0——实际每次议价只省 1 点耐心
- 对于耐心 3 的 HARD 型 NPC，1 点耐心等于 33% 的生存空间
- 对于耐心 5 的 SOFT 型 NPC，1 点耐心等于 20% 的生存空间

匠心精通"AP-1"的价值取决于 AP 总量。经济参数显示 AP = 10/天。如果原来每次鉴定消耗 1 AP，精通后变为 0（最低 1），那实际上**并不能变为 0，最低仍是 1**。所以是从 1 变为...还是 1？

**问题升级**: "鉴定消耗 AP -1（最低 1）"——如果基础消耗就是 1 AP，那 -1 后最低 1 = **没有效果**。这个精通奖励在当前参数下完全无效。

**建议**:
1. 确认鉴定基础 AP 消耗值——如果基础就是 1，匠心精通的"AP-1（最低 1）"形同虚设
2. 要么将基础 AP 消耗设为 2（使精通有意义），要么改变精通奖励内容（如"首次鉴定免费"或"鉴定偶尔不消耗 AP"）
3. 三条精通路径的经济价值需要重新平衡

### 5. 🔴 口口相传推荐客户的 ROI 分析与经济参数矛盾

**问题**: 口口相传推荐客户物品估价 $2000-$5000，品相中等偏上。需验证这个区间对明路玩家的实际经济贡献。

**分析**:
- 推荐客户携带物品估价 $2000-$5000，取中位数 $3500
- 明路玩家会以慈善(0%)或援助(5%)成交，当金 = 物品估价的 50-70%（典当行逻辑）
- 当金范围：$1000-$3500
- 慈善档(0%)利息 = 0，纯粹亏出去的资金
- 援助档(5%)利息 = 本金 x 5% x 7/7 = 本金 x 5%（假设标准 7 天期限）
- 以本金 $2000、援助档计算：利息收入 = $100
- 如果客户赎回：利润 = $100
- 如果客户不赎回（绝当）：变现 = 真实价值 x 80% = ~$3500 x 80% = $2800，利润 = $2800 - $2000 = $800

但明路玩家使用"额外关照"后物品标记"善缘"，过期后售价 +25%。
- 善缘加成后变现 = $2800 x 1.25 = $3500，利润 = $3500 - $2000 = $1500

**触发频率**:
- 伪随机机制：基础 25%，每次未触发 +8%，触发后重置
- 期望触发间隔：约每 3 次善缘交易触发一次
- 明路玩家如果日均 1-2 笔慈善/援助交易 + 额外关照，每 3 天约触发 1 次口口相传
- 推荐客户 3-5 天后到达，因此大约每 6-8 天有 1 个推荐客户

**日均 ROI**:
- 最好情况（绝当+善缘）：$1500 / 7天 = ~$214/天
- 普通情况（赎回）：$100 / 7天 = ~$14/天
- 考虑触发频率：每 7 天 1 个推荐客户 x 期望利润 ~$400 = ~$57/天

**与游戏经济对比**:
- 日均支出：$50 日常 + $143 医药费（$1000/7天）= $193/天
- 手术基金目标：$100,000 / 30天 = $3333/天需要
- 口口相传贡献 ~$57/天仅占日均需求的 1.7%

**结论**: 口口相传的经济贡献极其微弱。推荐客户本身不是收入来源——明路玩家必须以低利率/慈善成交这些推荐客户（否则违背"善行"定位），利润空间极小。善缘 +25% 售价加成只在绝当时生效，而明路玩家的客户（被善意对待）赎回概率应该更高。

**建议**:
1. 明路的经济回报不能仅依靠口口相传——需要重新定义明路的经济模型
2. 推荐客户的设计应该提供**更高质量的物品**（高知识池、高格物价值），而非仅仅是"多一个客户"
3. 或者推荐客户可以不遵守明路约束（推荐客户带来的不一定是典当业务，可能是直接卖出/委托鉴定等高利润业务）
4. 当前数据下，明路在经济上显著弱于暗路和标准路线，需要额外的补偿机制

### 6. 🟡 暗路环境代价的量化缺失——"客源-1"的经济影响模糊

**问题**: 第 8.3 节暗路环境代价定义了"清白 <30 时日均客户数 -1"，但未量化这对暗路经济的实际影响。

**分析**:
- 经济参数：每日最大客户数 = 4（1 叙事 : 3 填充）
- 客户 -1 意味着每天只有 3 位客户
- 暗路玩家的高利贷档收益：假设当金 $1500，利率 20%，利息 = $300/笔
- 少 1 个客户 = 少 ~$300/天利息收入
- 但暗路施压+攻心降低底价 20%（cap），每笔多赚 ~$280（假设平均底价 $1400 x 20% = $280）
- 3 个客户 x $280 额外利润 = $840/天来自底价降低
- 减去 1 个客户的损失 ~$300 = 净增 $540/天

**结论**: 即使客源 -1，暗路的净经济收益仍然正向。清白 <30 的惩罚不足以制衡暗路的经济优势。

**但要注意**：叙事客户数量减少影响更大——如果被减掉的是叙事客户，那暗路玩家错过的事件链可能导致后期剧情缺失。这是叙事层面的制衡，不是经济层面的。

**清白 <15 "执法关注"事件**也未量化：
- 概率多大？每天 5%？15%？
- 后果是什么？罚款多少？没收物品？
- 如果只是小概率小罚款，暗路玩家完全可以接受

**建议**:
1. 量化"执法关注"的概率和后果——应该足以让暗路 Day 20+ 的预期利润下降到与标准路线可比
2. 考虑客户 -1 改为 -2（清白 <15 时），使客源萎缩更有压迫感
3. 或者：低清白导致客户底价整体上升（谨慎客户不来了，来的都是精明人），从结构上降低暗路压价收益

### 7. 🟡 声誉调制系数 0.8~1.2 的实际影响幅度是否可感知

**问题**: 第 6.2 节定义调制系数范围 0.8x~1.2x，即 +-20% 浮动。需验证这个幅度是否足以让玩家感知。

**分析**:
- 施压基础效果 -8%：
  - 调制 0.8x → -6.4%（最差）
  - 调制 1.0x → -8.0%（中立）
  - 调制 1.2x → -9.6%（最佳）
  - 差异 = 3.2 个百分点
- 以 $1400 底价为例：
  - 0.8x: 底价降 $90
  - 1.2x: 底价降 $134
  - 差异 = $44
- 攻心(绝望者)基础 -12%:
  - 0.8x: $1400 x 12% x 0.8 = $134
  - 1.2x: $1400 x 12% x 1.2 = $202
  - 差异 = $68

**可感知性判断**:
- $44~$68 的差异在 $1400 底价中占 3-5%
- 由于游戏从不显示精确底价数值（只有定性描述），玩家实际上**无法直接感知**调制系数的影响
- 玩家只能通过"NPC 是否更容易让步"来间接推断——但这受到太多其他变量干扰（NPC 风格、耐心、让步概率随机性）
- 文档第 6.3 节承认"游戏从不明示声誉与技能的关联"，依赖玩家"逐渐发现"

**结论**: 0.8~1.2 的调制范围在当前信息隐藏设计下几乎不可感知。这不一定是坏事（涌现叙事的优雅之处），但文档应该诚实地承认这是一个"氛围设计"而非"策略杠杆"。如果希望成为策略杠杆，需要更强的调制范围（如 0.5~1.5）或更直接的反馈机制。

**建议**:
1. 在文档中明确标注调制系数属于"隐性系统"——玩家不必感知它也能获得好体验
2. 如果希望增强可感知性，考虑在修行面板上显示当前调制状态（"你的匠心技能因商誉声望而增强"），作为间接反馈
3. 不建议扩大调制范围——0.5~1.5 会导致极端情况下技能效果差异过大

### 8. 🟡 融合技能"两系平均"调制是否过度惩罚

**问题**: v1.1 将融合技能调制从"取较高值"改为"两系平均"。以暗路（旧影+匠心）为例验证。

**分析**:
- 极端暗路玩家：清白=0（旧影 1.2）, 商誉=60（匠心 1.04）
  - 旧较高: 1.2 → v1.0 规则
  - 平均: (1.2 + 1.04) / 2 = 1.12 → v1.1 规则
  - 差异: 0.08 = 6.7% 削弱

- 平衡暗路玩家：清白=35（旧影 1.06）, 商誉=55（匠心 1.02）
  - 取较高: 1.06 → v1.0
  - 平均: (1.06 + 1.02) / 2 = 1.04 → v1.1
  - 差异: 0.02 = 1.9% 削弱

- 中立玩家（50/50/50）:
  - 取较高: 1.0
  - 平均: (1.0 + 1.0) / 2 = 1.0
  - 差异: 0% — 无影响

**结论**: "取平均"主要惩罚极端路线玩家（-6.7%），对中间路线几乎无影响。这是合理的——极端特化应该有代价。v1.1 的设计意图（"防止单轴极化的玩家获得过大融合优势"）在数值上成立。

**但注意一个隐含问题**: 明路（匠心+灵韵）玩家如果人情=80、商誉=40：
- 灵韵调制: 0.8 + 0.4 x (80/100) = 1.12
- 匠心调制: 0.8 + 0.4 x (40/100) = 0.96
- 平均: (1.12 + 0.96) / 2 = 1.04
- 惜物如人/口口相传的调制仅 1.04 — 明路玩家做善事导致商誉偏低，反而惩罚了明路融合技能

**建议**: 这个隐含问题可能需要关注——明路玩家的行为模式（慈善档不给商誉，援助档也不给商誉）导致匠心调制偏低，拉低融合平均值。可以考虑让善行也给少量商誉（如援助档 +1 商誉），或者接受这是融合路径的天然代价。

### 9. 🟢 攻心 NPC 反应差异化的隐性数值问题

**问题**: 第 4.2 节攻心对不同 NPC 类型效果不同：绝望者 12%，普通 10%，富裕/精明者 6%。但"富裕/精明者"的定义标准未明确。

**分析**:
- 当前 NPC 系统使用 BehaviorTag（DESPERATE/STUBBORN/SUSPICIOUS/SAVVY/NAIVE/SENTIMENTAL）
- "绝望者"对应 DESPERATE——清晰
- "普通客户"对应谁？NAIVE? SENTIMENTAL? CALM?
- "富裕/精明者"对应 SAVVY? STUBBORN?
- 如果一个 NPC 同时有 DESPERATE + SAVVY 标签（绝望但精明），使用哪个效果？
- 议价系统定义了四种推拉风格（HARD/SOFT/SLY/CALM），这与 BehaviorTag 不是同一套分类

**建议**:
1. 明确攻心效果差异化的判定依据——使用 BehaviorTag 还是推拉风格
2. 定义多标签冲突的优先级规则
3. 建议使用推拉风格作为判定基准（SOFT→绝望者效果 12%，HARD→富裕者效果 6%，其他→10%），因为推拉风格是议价阶段的原生分类

### 10. 🟡 伪随机口口相传的数学验证

**问题**: 口口相传使用伪随机——基础 25%，每次判定未触发 +8%，触发后重置为 25%。文档声称"最多连续 ~6 次不触发即保证触发"。

**分析**:
- 第 1 次：25% 不触发概率 75%
- 第 2 次：33% 不触发概率 67%
- 第 3 次：41% 不触发概率 59%
- 第 4 次：49% 不触发概率 51%
- 第 5 次：57% 不触发概率 43%
- 第 6 次：65% 不触发概率 35%
- 第 7 次：73% 不触发概率 27%
- 第 8 次：81% 不触发概率 19%
- 第 9 次：89% 不触发概率 11%
- 第 10 次：97% 不触发概率 3%

连续 6 次不触发的概率 = 0.75 x 0.67 x 0.59 x 0.51 x 0.43 x 0.35 = **2.26%**

连续 10 次不触发的概率 = ... x 0.27 x 0.19 x 0.11 x 0.03 = **0.0001%**（几乎不可能）

文档说"最多连续 ~6 次"不太准确——连续 6 次不触发虽然只有 2.26% 概率，但并非"保证"。真正的"保证触发"需要等到概率达到 100%，即 (100 - 25) / 8 = 9.375 → 第 10 次时概率 = 25 + 9 x 8 = 97%，仍非 100%。**严格来说没有硬性保底**。

**期望触发间隔**:
$$E = \sum_{n=1}^{\infty} n \times P(\text{第n次触发}) \approx 3.2 \text{ 次}$$

这与文档描述的"期望每 ~3 次善缘交易触发一次"一致。

**建议**:
1. 修正文档措辞："最多连续 ~6 次不触发即保证触发"改为"连续 6 次以上不触发的概率 <3%，期望每 3 次触发一次"
2. 如果想要硬性保底，添加规则："连续 N 次未触发时强制触发"（如 N=6 或 N=8）

### 11. ⭐ 压价上限 20% 的 cap 设计——精确且优雅

**问题**: 这不是问题，这是亮点。

**分析**:
- v0.x 的 38% 最大压价被削减到 20% 硬 cap
- 第 8.2 节三个计算示例清晰展示了不同场景下 cap 的效果：
  - 中立玩家：理论 24% → 实际 20%，溢出仅 4%
  - 极端暗路：理论 30.72% → 实际 20%，溢出 10.72%——但不动声色的"不消耗耐心"不受 cap 限制
  - 温和暗路：理论 22.2% → 实际 20%，明察秋毫仍有 2.2% 的有效贡献
- 这个设计让暗路全套技能不会"废掉"——底价降低有上限，但耐心保护效果独立运作
- 计算顺序"先对每个技能应用声誉调制 -> 求和 -> cap 截断"清晰无歧义

**为什么优雅**: cap 在保护经济平衡的同时，通过"不受 cap 限制"的辅助效果（不动声色），确保了极端暗路玩家仍有动力解锁明察秋毫+不动声色，而非"cap 了就别学了"。这是多维度奖励设计的典范。

### 12. ⭐ 精魄获取道德加成的可感知性大幅改善

**问题**: 亮点。

**分析**:
- v1.0 的 +2/+1 加成占日产出 3.3%——不可感知
- v1.1 的 +4/+2 加成：
  - 全慈善：灵韵 +16~20/天，占基础 60 的 27-33%——**显著可感知**
  - 全高利贷：旧影 +16~20/天，同上
  - 全标准：匠心 +8~10/天，占基础 13-17%——可感知但不强烈
- 这解决了 v1.0 评审的核心问题：行为塑造能力的反馈循环现在真正可感知
- 加成在夜间阶段自动获得，与格物产出独立——不增加操作复杂度

### 13. 🟡 善缘标签 +25% 售价的触发条件与明路经济模型的张力

**问题**: 善缘物品"过期死当后流转，售价 +25%"——但这要求物品过期，而明路玩家的客户理应更倾向赎回。

**分析**:
- 惜物如人触发条件：慈善(0%)或援助(5%)成交
- 善缘标签附加效果：过期后售价 +25%
- 但是：
  - 慈善档 → 客户 hope +5 → 赎回概率更高
  - 明路玩家使用额外关照 → hope +3 → 赎回概率再次提高
  - 如果又有抚慰技能 → hope +5/+8 → 赎回概率更更高
- 明路的一切行为都在提高客户赎回概率，而善缘 +25% 只在**不赎回**时生效
- 这产生了一个悖论：**明路玩家越做善事，善缘标签触发率越低**

**量化**:
- 假设正常赎回率 50%，明路加成后赎回率 70%
- 善缘 +25% 实际触发率 = 30%（不赎回的概率）
- 期望附加收益 = 30% x 25% x 平均售价 = 7.5% 的平均售价提升
- 对比暗路：高利贷导致赎回率下降，更多物品绝当，暗路的基础变现效率已经更高

**建议**:
1. 这个悖论虽然存在，但可以被接受为设计意图——善缘 +25% 是"安慰奖"，不是主要回报
2. 文档应明确标注：善缘售价加成是惜物如人的**附带效果**，口口相传的推荐客户才是明路的主要经济机制
3. 但如发现 5 所分析，口口相传的经济贡献也很弱——明路整体经济模型需要重新审视

### 14. 🟢 洞若观火"流转估值范围"的精度问题

**问题**: 赎回意愿为"低"时显示物品的流转估值范围。但"估值范围"的精度未定义。

**分析**:
- 物品有"真实价值"（Real Value），流转估值应该基于真实价值 x 绝当变现比例(80%)
- 但洞若观火是被动技能，不消耗 AP，在议价开始时自动触发
- 如果流转估值太精确（如 "$2,800-$3,200"），等于免费获得了接近真实价值的信息
- 如果流转估值太模糊（如 "$1,000-$5,000"），信息无决策价值
- 当前鉴定系统的估价区间从初始 +-30% 逐步收窄——洞若观火应该与鉴定进度挂钩

**建议**:
1. 流转估值范围应基于当前已知的估价区间，而非真实价值——即"流转估值 = 当前估价区间 x 80%"
2. 这样：
   - 未鉴定时：流转估值范围很大（如 $800-$3200），需要配合鉴定收窄
   - 已鉴定时：流转估值范围精确（如 $2400-$2800），可直接用于决策
3. 这维持了"信息有代价"的设计哲学——洞若观火提供的是**决策框架**（"这是买入不是借出"），而非免费精确估值

## 总体评价

v1.1 在数值一致性方面相比 v1.0 有显著提升。前次评审的所有 P0 问题（压价计算示例缺失、明路动机真空、暗路无代价循环、道德加成过弱）全部修复到位。新增的环境代价、伪随机机制、Floor/Ask 关系文档化等补充都是必要且正确的。

**当前剩余的核心数值风险集中在两个区域**：

**第一，精魄经济的上游锚定仍不完整**。日均 60 点产出是基础格物裸值，但玩家每晚 3 点精力需要在格物/修复/重铸/修行四者间分配，实际可用于修行的精魄远低于 60。12 技能消耗的 1 点精力机会成本（~25 精魄等价）也未被计算在内。匠心精通奖励"AP-1（最低 1）"在基础 AP=1 的参数下可能完全无效。这些不影响设计方向，但在实现前需要确认精力分配模型和精通奖励的有效性。

**第二，三条路径的经济回报仍不对称**。暗路的即时确定性收益（底价降低 20%）vs 明路的延迟概率性收益（口口相传推荐客户每 6-8 天一个，且必须以低利率成交）差距显著。善缘 +25% 售价因明路行为提高赎回率而自我削弱。暗路环境代价（客户 -1）的量化不足以制衡其经济优势。标准路线（匠心/商誉）的精魄加成仅为极端路线的一半。这些不对称性不一定是坏事——叙事游戏中"善良路线更难"是经典设计——但需要在文档中被有意识地承认和管理，而非隐含在数值中被忽视。

建议在下一轮迭代中：(1) 在经济参数文档中建立精魄经济子章节，固定精力分配模型；(2) 对三条路线进行 30 天 spreadsheet 模拟，验证各路线的经济曲线是否在设计意图范围内。
