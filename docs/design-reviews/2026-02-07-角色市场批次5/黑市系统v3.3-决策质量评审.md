# 黑市系统 v3.3 — 决策质量与信息平衡评审

> **评审日期**: 2026-02-07
> **评审对象**: `黑市系统 (Black Market System).md` v3.3
> **评审视角**: 决策质量与信息平衡 (Decision Quality & Information Balance)
> **理论基础**: Tynan Sylvester - Decisions, Motivation, Skill
> **关联文档**: 典当业务系统 v1.6, 新闻与传闻系统 v1.1, 鉴定系统 v1.7, 经济参数 v1.1

---

## 发现列表

### 1. :star: 双轨制的决策张力是天然的信息平衡典范

**分析**：双轨制（黑市收购 vs 玩家出售）是本设计最出色的决策结构。它完美体现了 Sylvester 所说的"有意义的决策基于非显而易见地使用以显而易见的方式运作的机制"：

- **机制以显而易见的方式运作**：收购 = 高价但限品类、出售 = 低价但随时可用。规则极其清晰。
- **使用方式非显而易见**：何时等待、何时割肉、手头有 3 件可收购物品但只有 2 个额度该选哪个——这些决策都不显而易见。

更妙的是，医药费的时间压力（每 7 天 $1,000）将这个博弈从"经济最优化"提升为"生存 vs 利润"的深层决策（Profound scope, 10+ 秒思考）。

**结论**：核心框架优秀，值得保留。后续发现均在此基础上做微调。

---

### 2. :red_circle: 收购标签生成的"纯随机"导致严重的信息饥荒

**问题**：文档 2.1 节明确写道"纯随机，每个标签等概率"。这意味着玩家对"明天黑市收什么"完全无法预测，除非恰好命中新闻暗示（3.3 节提到"投资者关注贵金属"有 70% 概率次日收购该标签）。

**分析**：Sylvester 指出"对一个有意义的决策，结果必须既非不可知也非必然——它们必须是部分可预测的"。当前设计中：

1. **新闻暗示是唯一的预测渠道**，但新闻系统 v1.1 没有规定每天必然有黑市方向暗示——它可能被叙事回响和环境噪音挤占（优先级：剧情后果 > 商业情报 > 环境噪音）。
2. **无暗示时 = 纯猜测**。"今天囤古董还是电子产品"变成扔硬币，这是 Sylvester 所说的 Information Starvation（信息饥饿）。
3. **囤货策略被架空**：场景一"策略囤货"的体验需要玩家能合理推测方向，但纯随机让"耐心"变成"运气"。

**建议**：引入"部分可预测性"机制，至少做到以下之一：
- (a) 保证每天新闻中至少有一条商业情报（不被叙事完全挤占）；
- (b) 引入"需求惯性"——某标签连续被收购时，次日复现概率略高（如 30%），模拟市场趋势；
- (c) 黑市联系人升级到 Lv3+ 时，前一晚提示"明天可能收什么"（模糊暗示，非确定信息）。

### 3. :yellow_circle: 佣金等级信息完全透明，削弱了声誉投资的决策深度

**问题**：3.1 节的佣金模型（Underworld 0-19 = 20%, 20-39 = 15%, ..., 80+ = 0%）对玩家完全透明。玩家可以精确计算：我需要 Underworld 达到多少才值得交易。

**分析**：这是典型的 Information Glut（信息过载）。当佣金费率、声誉阈值都明确时，"要不要提升 Underworld"从深层决策退化为算术题：

- 每次 Underworld 提升 5 点减少多少佣金 = 可精确计算
- 负面后果（保护费 $200-500 / 7-14 天）也完全透明 = 可精确计算净收益
- 决策变成"我的交易量是否足够大到佣金节省 > 保护费支出"，答案对任何特定游戏状态是唯一的

Sylvester 强调：决策的价值来自"将信息隐藏在未来的因果链复杂性中"。当所有数字都可见时，决策的精神工作量趋近于零。

**建议**：
- 将佣金费率从精确数字改为模糊范围描述（"熟客待遇"而非"10%"），让玩家只能感知到"更便宜了"而非"恰好便宜了 5%"；
- 或者让佣金费率有浮动成分（基础 10% +/- 2% 随日波动），维持策略空间。

### 4. :red_circle: 热度系统的风险事件判定存在"决策后空白期"

**问题**：4.3 节描述风险事件"每次交易后判定"，但判定结果的呈现和玩家的应对存在严重的心流间隙（Flow Gap）。

**分析**：考虑以下场景——玩家在黑市卖了一件物品，热度从 4 升到 6（关注 -> 警告）。系统掷骰：30% 概率触发事件。

- 如果**没触发**：玩家获得的反馈仅仅是热度条变色。大脑无事可做——"好的，没事发生，继续"。这是一个 Flow Gap。
- 如果**触发了便衣暗访**：当晚黑市关闭，玩家被动接受结果，无法做任何决策。又一个 Flow Gap。
- 只有**搜查警告**提供了真正的决策（破财消灾 vs 暂避风头），但它只在"警告+"等级才出现。

Sylvester 用"玩家的大脑是一个底部有洞的小杯子"来比喻——水（决策）必须持续流入，既不溢出也不干涸。当前设计在低热度时几乎没有水流入（交易 -> 数字变化 -> 结束），在高热度时偶尔有水但多数时间仍然干涸。

**建议**：
- (a) 给"未触发事件"的交易增加微叙事反馈——联系人发一条短信："这批货处理得挺干净"或"外面有人在打听你的事，下次小心"。不是决策，但维持心理张力（Sylvester 所说的"感受可能性"）。
- (b) 将便衣暗访从"纯被动"改为带有微决策："联系人警告你今晚有眼睛，你要不要冒险再做一单？"——给玩家一个 twitch/tactical 级别的快速决策。

### 5. :yellow_circle: 高 Underworld 负面后果的"保护费"决策过于显而易见

**问题**：6.3.A 节的保护费选择——交 $200-500 vs 黑市锁定 3 天 + Underworld -5——在几乎所有情况下有明显最优解。

**分析**：让我们做简单的期望值分析：
- 3 天锁定期间，如果玩家每天能通过黑市获利 $200-400（保守估计），锁定的机会成本 = $600-1200。
- 因此，交 $200-500 几乎总是更优。只有在现金极度紧张时才会选"暂避风头"。
- 更关键的是：Underworld -5 在高声誉区间的实际影响可忽略（80 -> 75 仍然是"老主顾"级别）。

这构成了 Sylvester 所说的"答案显而易见的假决策"（Non-decision）。玩家不需要思考，直接选"交钱"。

**建议**：增加权衡维度，让两个选项各有独特价值：
- 方案 A：保护费金额提高到与锁定成本可比（$500-1000），且每次交钱后下次保护费涨价（通胀机制），让长期成本不可忽视；
- 方案 B：暂避风头除了 -3 热度外，额外获得"清白期"buff——避风头结束后的 3 天内热度衰减翻倍，创造"先忍后爽"的策略深度；
- 将两个选项的信息差异化：交钱的具体金额已知但后续涨价未知，暂避风头的冷却奖励显示但热度恢复速度模糊——让两边都有"部分可预测"的特征。

### 6. :star: 鉴定精度与黑市波动的联动创造了优雅的跨系统决策

**分析**：2.4 节的设计——uncertainty 影响黑市价格波动幅度——是跨系统决策设计的典范。它创造了一个完美的"非显而易见使用"场景：

- **机制显而易见**：鉴定越充分，价格越稳定。这个因果关系清晰易懂。
- **使用非显而易见**：玩家在收货时（白天）投入的 AP 影响的是卖货时（夜间黑市）的波动。时间上的分离让决策不是立即可验证的——需要经过"鉴定 -> 入库 -> 观察价格 -> 决定卖出时机"的多步链条。

更出色的是**非对称分布设计**（下行幅度 >> 上行幅度）。它让盲收在统计上是劣策略，但偶尔的正偏差保留了"赌一把"的刺激感——这恰好对应 Sylvester 的可变比例强化：不总是亏，但期望值为负，创造了"明知道不该赌但忍不住"的心理张力。

**结论**：这是本文档最精巧的设计之一，且与鉴定系统 v1.7 的连续函数模型完美契合。

### 7. :yellow_circle: 升级等级表的决策粒度不均匀——Lv1-Lv2 几乎无感

**问题**：4B.1 节的升级等级表中，Lv1 -> Lv2 的变化仅为"收购限额 3 -> 4"。热度衰减不变（-1），收购价加成不变（+0%）。

**分析**：从决策质量角度看：
- Lv1 -> Lv2：+1 收购额度 = 微弱的数值提升，几乎不改变玩家的策略行为
- Lv2 -> Lv3：热度衰减翻倍（-1 -> -2）+ 收购价 +5% = 策略性质变（"关键节点"）
- Lv3 -> Lv4：+1 额度 = 又一个微弱提升
- Lv4 -> Lv5：额度 6->8 + 衰减 -2->-3 + 加成 5%->10% = 终极升级

Sylvester 在 Skill 章节中强调"弹性挑战"——不同水平的玩家都应获得有意义的体验。Lv1-Lv2 的升级缺乏"感知到的改变"，投资回报感不足。玩家在 Lv1 时的核心决策（"我该升级黑市还是升级其他系统"）因为 Lv2 的回报太弱而变成了"显然先升别的"。

**建议**：
- Lv2 增加一个小而有特色的能力——例如"联系人偶尔透露明日收购方向"（呼应发现 #2 的信息饥饿问题）；
- 或者将 Lv2 的热度衰减改为 -1.5（取整为 -2 时 50% 概率），创造一个值得投资的中间台阶。

### 8. :red_circle: "赃物交易"决策缺乏足够的前置信息——信息饥饿场景

**问题**：7.1 节提到赃物可售但热度 +1，4.2 节也提到赃物额外 +1 热度。然而，玩家在**收赃时**（白天业务阶段）对"这件物品会在黑市上产生多少额外热度"的信息是割裂的。

**分析**：收赃的决策链条如下：

```
白天：客户带来赃物 -> 决定是否收 -> 收下
夜间：打开黑市 -> 发现赃物在出售区标注"+1热度" -> 决定卖不卖
```

问题在于：**收赃时的决策**（白天）和**卖赃的后果**（夜间热度）被时间和界面隔开了。玩家在白天收赃时，需要预判：

1. 这件赃物的黑市价格是多少（取决于 uncertainty）？
2. 卖出时会产生多少热度（+2 普通出售 + 1 赃物 = +3）？
3. 当前热度水平加上这个增量会不会触发风险事件？

这些信息在白天收赃界面上完全不可见。Sylvester 强调：如果预测需要的信息散布在多个无法同时查看的界面上，决策就退化为"先做了再说"——这是信息饥饿的变体。

**建议**：
- 在白天的赃物收购决策面板上增加"黑市风险提示"——例如："当前热度: 关注 (4/10)。出售此赃物预计 +3 热度 -> 警告 (7/10)"；
- 或者让鉴定系统在发现 STOLEN 特征时，商人直觉除了提示"这可能是赃物"外，额外提示黑市热度影响："卖这东西得小心，风声会紧不少。"

### 9. :yellow_circle: 风险事件的"触发概率"展示创造了可计算的伪决策

**问题**：8.4 节提到"热度 >= 关注时，显示触发概率"。即直接告诉玩家：当前交易后有 15%/30%/50% 概率触发事件。

**分析**：这再次构成 Information Glut。当玩家知道精确概率时：
- 15% 触发率 = "风险可接受，卖"（几乎是非决策）
- 30% 触发率 = 需要简单的期望值计算（利润 vs 30% 的惩罚期望值）
- 50% 触发率 = 通常选择不卖（也是非决策）

Sylvester 在 Poker 案例中展示的核心洞察是：隐藏的信息才创造决策。当概率完全透明时，玩家做的不是"决策"而是"计算"。

**建议**：
- 将精确概率替换为模糊的叙事描述："联系人看起来很紧张"、"空气中弥漫着不安"；
- 让玩家通过行为（连续交易 vs 间隔交易）来"感受"风险等级，而非直接读取数字；
- 保留热度等级颜色指示（绿/黄/橙/红），但移除具体百分比。

### 10. :star: 违约出售的道德决策信息设计精妙

**分析**：7.1-7.2 节中赎回期内物品出售的设计呈现了理想的信息平衡。玩家面对的决策包含：

- **已知信息**：物品价值、当前资金、声誉影响（人情-3, 商誉-1）、会触发事件链
- **部分可知信息**：NPC 事件链的后果（知道会有但不确定具体是什么）
- **隐藏信息**：违约对游戏后期的长远影响

这恰好符合 Sylvester 的理想信息平衡：足够的信息让决策不是盲猜，但足够的不确定性让答案不是显而易见的。UI 上的"赎回期"警示标记和确认对话框进一步强化了"这是一个重大决策"的感知。

### 11. :yellow_circle: 玩家出售的出售系数波动因素之间缺乏可感知的归因

**问题**：2.2 节列出出售系数的四个波动因素：基础随机(0.65-0.80)、品类行情(+/-5%)、新闻联动(+/-5%)、鉴定精度。但这些因素在最终价格中**混合呈现**为一个单一数字。

**分析**：Sylvester 的决策理论核心是"一致的系统以可预测的方式运作"。当四个因素叠加后只显示一个最终价格时，玩家无法分辨：

- "今天这个金表价格低是因为基础随机差、还是因为品类行情不好、还是因为我没鉴定？"
- 如果玩家无法归因，就无法学习系统规律，决策退化为"看价格高就卖"的反射行为

新闻系统设计的核心美学是"模糊性"，但黑市价格系统应该是可学习的——两者的设计哲学存在矛盾。

**建议**：
- 在价格旁边显示微弱的归因提示。例如："$720 (-28%)" 旁边加小图标：波浪线 = 高波动(uncertainty)，箭头向下 = 行情低迷(新闻)。不需要精确数字，但给玩家可学习的视觉线索；
- 或者让鉴定充分的物品（低 uncertainty）的价格标签样式不同于盲收物品——例如实线框 vs 虚线框——暗示"这个价格我更有信心"。

### 12. :yellow_circle: 黑市升级与声誉佣金之间的决策缺乏交叉张力

**问题**：当前设计中，升级系统（Lv1-5）和佣金系统（Underworld 0-100）是两条平行的成长线。两者都是"越高越好"，没有相互制约。

**分析**：两条线的叠加效果：

| 阶段 | 升级 | 声誉 | 效果 |
|------|------|------|------|
| 早期 | Lv1 | 低 (20%) | 低额度 + 高佣金 = 几乎不值得用 |
| 中期 | Lv3 | 中 (10%) | 有用但不惊人 |
| 后期 | Lv5 + 80声誉 | 0% 佣金 + 10% 加成 | 黑市变成纯利润机器 |

问题是：在整个成长过程中，玩家的策略从未需要在"升级"和"声誉"之间做取舍。它们不竞争任何资源（升级花钱，声誉通过行为积累），不相互抵消。这意味着成长路径是单调的"两条都往上爬"，缺乏 Sylvester 所说的"有意义的权衡"。

**建议**：
- 考虑让高等级升级需要一定的 Underworld 声誉门槛（如 Lv4 需要 Underworld 40+），将两条线编织在一起——玩家必须决定"要不要做更多灰色交易来解锁下一级"；
- 或者让高升级等级本身增加热度基准值（Lv5 = 每日基础热度 +1），创造"能力越强、暴露越多"的内在矛盾。

### 13. :yellow_circle: "危险任务"事件的信息结构过于二元

**问题**：6.3.B 节的危险任务——接受(+3 Underworld, 可能触发连锁)vs 拒绝(-5 Underworld, 关系冷淡)——是一个典型的二选一决策，但信息结构过于对称。

**分析**：玩家看到的是：

- 接受 = Underworld +3 + "可能有好事也可能有坏事"（模糊）
- 拒绝 = Underworld -5（精确）

"可能后果"列表（警方搜查/帮派纷争/顺利完成）虽然增加了不确定性，但玩家无法获得任何线索来判断哪种后果更可能。这不是"部分可预测"——而是纯赌博。Sylvester 会将其定义为信息饥饿下的伪选择。

**建议**：
- 让危险任务的邮件内容包含**可解读的线索**——例如："有批货需要在你这放几天"（暗示警方风险高）vs "需要你帮忙传个话"（暗示帮派纷争风险高）。不同的任务描述暗示不同的风险分布；
- 让新闻系统提供相关信号——如近期有"严打"新闻时接受任务的被查概率更高，玩家可以通过交叉验证信息做出"有根据的推测"。

### 14. :green_circle: 黑市界面缺少"决策回顾"机制——交易历史不可追溯

**问题**：UI 设计（8.2 节）只展示当前状态（今日收购、自由出售），没有交易历史。

**分析**：Sylvester 在信息平衡中指出，学习需要因果反馈。如果玩家无法回顾自己过去的交易记录（卖了什么、赚了/亏了多少、当时热度是多少），就无法从经验中学习。这不影响单次决策质量，但影响跨游戏日的策略学习能力。

**建议**：
- 在黑市界面增加一个"交易记录"标签页，显示最近 7 天的交易摘要（物品名、买入价/卖出价、利润、热度变化）；
- 这为玩家提供了策略回顾的基础，也暗示"你的每一笔交易都被记录在案"的叙事张力。

---

### 15. :star: 流当结算走黑市价是简洁而优雅的设计

**分析**：2.4 节末尾写道"流当后的自动结算 = 按当天该物品的黑市出售价卖出"。这个设计通过复用已有机制（黑市出售价 = 含 uncertainty 波动的价格），消除了单独的流当变现逻辑，同时保留了鉴定投资的回报路径。

从决策角度看，这创造了一个优雅的决策链：
1. 白天鉴定降低 uncertainty -> 夜间黑市价格更稳定 -> 流当结算时不会被波动坑
2. 玩家可以主动选择"在黑市高价时手动卖出"vs "等到流当自动结算"
3. 两种路径的期望值不同但都有 uncertainty 的影子

这是 Sylvester 所说的"优雅 = 用最少的机制复杂度产生最多的决策多样性"。

## 亮点

- **双轨制核心框架**（发现 #1）：收购 vs 出售的博弈结构天然产生高质量决策，信息平衡恰到好处
- **鉴定精度 x 黑市波动联动**（发现 #6）：跨系统、跨时间的决策链条设计精巧，非对称分布保留了"赌一把"的心理张力
- **违约出售的道德决策**（发现 #10）：已知/部分可知/隐藏信息的三层结构完美
- **流当结算复用黑市价**（发现 #15）：机制复用消除冗余，同时保留决策空间

## 总体评价

黑市系统 v3.3 的核心决策结构——双轨制交易 + 鉴定精度联动 + 热度风险——展现了相当成熟的设计思维。双轨制本身就是一个信息平衡的教科书案例：玩家拥有做出有意义决策所需的充足信息，但答案从不显而易见。鉴定精度与黑市波动的联动更是跨系统决策的亮点，它让白天的 AP 投资在夜间有了持续可感知的回报。

但在具体执行层面存在若干信息平衡问题。最严重的是收购标签的纯随机生成（发现 #2），它将"策略囤货"的核心体验从"有根据的推测"降级为"纯运气"。其次是佣金费率（发现 #3）和风险概率（发现 #9）的过度透明，将本应是深层决策的权衡变成了可直接计算的算术题。热度系统的心流间隙（发现 #4）和保护费的假决策（发现 #5）也需要关注——前者让玩家大脑在交易间隙无事可做，后者让一个本应痛苦的抉择变成了无需思考的例行操作。

总体而言，框架优秀，细节可打磨。建议优先处理收购标签的可预测性（#2）和热度系统的心流间隙（#4），这两项直接影响每日游戏体验的核心质感。
