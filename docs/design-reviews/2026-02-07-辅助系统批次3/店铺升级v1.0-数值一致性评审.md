> **评审视角**: 数值一致性与经济平衡
> **关联文档**: 经济参数.md v1.1, 昼夜循环与晚间玩法.md v1.4, 议价谈判系统.md v1.4, 核心愿景.md v1.0

## 发现列表

### 1. RED 光谱仪偏差率公式在设计文档与代码实现中不一致

**问题**：设计文档定义偏差率公式为 `|估价 - 实际价值| / 估价 x 100%`，即以**估价**为分母；而代码实现 (`utils.ts` 第 257 行) 使用 `difference / realValue * 100`，即以**实际价值 (realValue)** 为分母。

**分析**：这两种计算方式在偏差较大时结果差异显著。

| 估价 | 实际价值 | 设计文档公式 (除以估价) | 代码公式 (除以实际价值) |
|------|---------|----------------------|----------------------|
| $1000 | $500 | 50% | 100% |
| $500 | $1000 | 50% | 50% |
| $800 | $500 | 37.5% | 60% |
| $300 | $1000 | 70% | 70% |

当物品被高估时 (估价 > 实际价值)，代码公式会放大偏差率（例如估价$1000、实际$500，设计文档得50%刚好触发Lv1阈值，代码得100%远超阈值）。当物品被低估时两种公式差距较小。这意味着代码实现中光谱仪对"高估/赝品"类物品更敏感，而对"低估/捡漏"类物品的表现与设计一致。

**建议**：统一公式。建议以**实际价值**为分母（代码当前做法），因为这在数学上更直觉（"偏离真值多少百分比"），但需要相应调整设计文档中的公式描述和阈值数值（Lv1的50%阈值在以实际价值为分母时可能过于敏感）。或者，如果设计意图是"估价的可信度"视角，则以估价为分母更合理，此时需修改代码。

### 2. RED 设计文档未包含"黑市联络网"升级项，但代码已实现

**问题**：店铺升级系统设计文档v1.0列出了5个升级项（储物架扩展、精密工作台、茶具套装、光谱分析仪、预约板），但代码中 `config.ts` 还包含第6个升级项 **"黑市联络网 (Black Market Contact)"**，共5级，总投资 $31,500。

**分析**：
- 黑市联络网的费用曲线为 $1000 / $2500 / $5000 / $8000 / $15000，总计 $31,500
- 它属于后间升级（无维护费）
- 提供黑市解锁、每日收购数量、热度衰减、收购价加成等效果
- 设计文档第8节提到"总投资额约 $50,000"，但文档中列出的5个升级项总投资额计算如下：
  - 储物架: $500+1000+2000+4000+8000 = $15,500
  - 精密工作台: $1500+3000+6000 = $10,500
  - 茶具: $800+1500+3000 = $5,300
  - 光谱仪: $2000+4000+8000 = $14,000
  - 预约板: $1000+2000+4000+7000+12000 = $26,000
  - **文档5项总计: $71,300**（已超过文档声称的"约$50,000"）
  - 加上黑市联络网: $71,300 + $31,500 = **$102,800**

这揭示了两个子问题：(a) 文档缺失黑市联络网；(b) 文档中"约$50,000"的总投资估算严重不准确。

**建议**：
1. 将黑市联络网加入设计文档
2. 修正总投资额估算。实际上全满级需要 $102,800，几乎等于通关目标 $100,000。这意味着**全满级升级在单次通关中基本不可能实现**，需确认这是否为设计意图。如果希望玩家在通关前能升满大部分升级，需降低费用或减少等级数。

### 3. YELLOW 升级总投资额与通关目标的比例问题

**问题**：如发现2所述，全升级总费用 $102,800 已超过通关目标 $100,000。加上游戏过程中的周期性支出（医药费、日常开支、维护费），玩家在通关前能投入升级的资金极为有限。

**分析**：假设游戏30天通关（4周+）：

| 支出类别 | 估算 |
|----------|------|
| 医药费 | $1,000 x 4 = $4,000 |
| 日常开支 | $50 x 30 = $1,500 |
| 不定时小额医疗 | ~$600 (估计) |
| 柜台维护费 (全开最高级) | $130/天 x 30 = $3,900 |
| **运营总支出** | **~$10,000** |
| 手术基金目标 | $100,000 |
| 初始资金 | $10,000 |
| **需赚取总额** | $100,000 + $10,000 - $10,000 = **$100,000** |
| 若全升级 | 额外 $102,800 |
| **理论需赚取** | **$212,800** |

这意味着玩家实际上只能选择性投资部分升级。这本身不是问题（资源分配困境是设计意图），但需要确保：
- 玩家在第一周（$10,000初始资金内）有足够的入门级升级可选（当前最低入门升级$500储物架Lv1是合理的）
- 不同"升级路线"之间有明确的策略差异

**建议**：
1. 在设计文档中明确"预期升级轨迹"：玩家在通关过程中大约能投入多少资金到升级？建议 $15,000-$25,000 范围
2. 标注"核心升级"（玩家几乎必须购买）vs "奢侈升级"（风格化选择）
3. 考虑按游戏节点解锁升级，而非全部从Day 1可见——减少早期认知负担

### 4. YELLOW 储物架扩展的 effectValue 语义可能导致混淆

**问题**：储物架扩展的 `effectValue` 列在设计文档和代码中定义为 Lv1=1, Lv2=2, Lv3=3, Lv4=4, Lv5=5。这看起来像是"当前等级提供的总加成"，而非"本次升级的增量"。也就是说，从Lv1升到Lv2时，容量从6变为7（+1），而不是从6变为9（+2增量）。

**分析**：代码 `computeUpgradeEffects` 直接使用 `levelConfig.effectValue` 赋值，因此 Lv2 的 effectValue=2 表示"比基础多2个位"，累计容量=5+2=7。这与设计文档的"累计容量"列吻合。但这意味着：
- Lv1到Lv2的花费 $1,000 只增加了1个库存位
- Lv4到Lv5的花费 $8,000 也只增加了1个库存位

**每个库存位的边际成本**：

| 升级 | 花费 | 新增位数 | 每位成本 |
|------|------|----------|----------|
| Lv1 | $500 | +1 | $500/位 |
| Lv2 | $1,000 | +1 | $1,000/位 |
| Lv3 | $2,000 | +1 | $2,000/位 |
| Lv4 | $4,000 | +1 | $4,000/位 |
| Lv5 | $8,000 | +1 | $8,000/位 |

边际成本以2倍指数增长。这个增长率是否合理取决于每个库存位带来的经济价值。

**建议**：确认设计文档中"效果"列的"+N库存位"描述是"总加成"还是"增量"。当前描述为 `+1, +2, +3, +4, +5`，暗示总加成语义，但容易被误读为增量。建议改为显式写法如"总共+2库存位（累计7位）"。

### 5. YELLOW 茶具套装的ROI分析：Lv3的维护费可能过高

**问题**：茶具Lv3提供+3耐心，每日维护费$50。需要分析这$50/天的投入是否带来足够回报。

**分析**：

从Lv2升到Lv3的升级成本为$3,000，额外维护费为$50-$35=$15/天。增量效果为耐心从+2变为+3（仅+1耐心）。

耐心在推拉系统中的价值：
- 每点耐心 = 大约1轮额外议价机会（概率制，不是固定消耗）
- 强硬型NPC基础耐心3，加上Lv3茶具变为6，翻倍
- 软弱型NPC基础耐心5，加上Lv3变为8，提升60%

额外1点耐心带来的经济收益难以精确量化，但考虑每天4个客户，每个客户的议价差额大约在$50-$200区间（粗略估算），额外1点耐心可能每天带来$50-$100的额外利润。

**维护费占日收入比例**：
- 假设日均毛收入$300-$500
- $50维护费占比10%-17%，这个比例较高
- 加上Lv3光谱仪$80/天，两者全开 = $130/天，占日收入26%-43%

**建议**：
1. 考虑将Lv3茶具维护费从$50降至$40，让Lv2到Lv3的增量维护费更温和（$5/天而非$15/天）
2. 或者Lv3提供额外效果（如"偶尔恢复1点已消耗耐心"），增加升级感知价值

### 6. YELLOW 光谱仪的检测阈值与赝品检测有效性

**问题**：光谱仪Lv1的检测阈值为偏差>50%。需要分析这在赝品检测场景中的实际有效性。

**分析**：

赝品的特征是"估价远高于实际价值"。以代码中的公式 (除以realValue) 为准：
- 一个估价$500的赝品，实际价值$100 → 偏差率 = 400%，任何级别都能检测
- 一个估价$500的赝品，实际价值$300 → 偏差率 = 67%，Lv1能检测
- 一个估价$500的赝品，实际价值$350 → 偏差率 = 43%，Lv1**无法检测**

但按设计文档的公式 (除以估价)：
- 估价$500，实际$300 → 偏差率 = 40%，Lv1**无法检测**
- 估价$500，实际$250 → 偏差率 = 50%，Lv1刚好触发

这表明在设计文档的公式下，Lv1光谱仪只能检测到估价偏差超过一半的极端赝品。对于"高仿"赝品（估价与实际差距30-50%），需要至少Lv2才能检测。

另外，光谱仪对"捡漏"（实际价值高于估价）的检测在两种公式下差异显著：
- 估价$500，实际$1000：文档公式100%，代码公式50%
- 估价$500，实际$700：文档公式40%，代码公式29%

**建议**：
1. 首先解决发现1中的公式不一致问题
2. 文档应明确列出几个典型场景的检测结果，让策划直观理解各级阈值的实际效果
3. 考虑Lv1阈值是否设得太宽松（50%偏差已经很大了）——如果大多数赝品的偏差率<50%，则Lv1几乎无用

### 7. YELLOW 预约板的费用曲线陡峭度异常

**问题**：预约板5级总费用$26,000，且Lv4($7,000)到Lv5($12,000)的跳跃幅度为71%，而其他升级项从倒数第二级到最后一级的跳跃幅度为100%（翻倍）。

**分析**：

各升级项的费用倍率（每级相对上级）：

| 升级项 | Lv1->2 | Lv2->3 | Lv3->4 | Lv4->5 |
|--------|--------|--------|--------|--------|
| 储物架 | 2.0x | 2.0x | 2.0x | 2.0x |
| 精密工作台 | 2.0x | 2.0x | - | - |
| 茶具 | 1.88x | 2.0x | - | - |
| 光谱仪 | 2.0x | 2.0x | - | - |
| 预约板 | 2.0x | 2.0x | 1.75x | 1.71x |
| 黑市联络网 | 2.5x | 2.0x | 1.6x | 1.88x |

预约板和黑市联络网的高级别倍率递减（费用增长放缓），与储物架的恒定2.0x形成对比。这不一定是问题，但在预约板Lv4仅增加1个邀请名额（从1人到2人）、Lv5仅增加1个候选人和筛选偏好的情况下，$12,000的定价是否物有所值需要考量。

**建议**：
1. 验证预约板Lv5的$12,000定价是否合理——筛选偏好的实际经济价值取决于不同紧迫度客户的利润差异
2. 如果认为高级预约板更多提供"便利性"而非直接收益，当前定价可能过高
3. 考虑统一费用增长曲线，或在文档中解释为什么不同升级项有不同的增长率

### 8. YELLOW 精密工作台的ROI依赖未定义系统

**问题**：精密工作台增加夜间精力上限，但其经济价值完全取决于格物/重铸/修复系统的收益产出，而这些子系统的数值参数在本文档中未详述。

**分析**：

精密工作台总投资 $10,500（Lv1-3），提供 +3 精力（从3变为6）。但精力的经济价值取决于：
- 格物每点精力能提取多少知识点数（game.toml: 每次20点，容量100点）
- 重铸/修复消耗多少点数，能增加多少物品价值
- 这些价值能否转化为现金

如果每点精力的经济等价值很低，则$10,500的投资回本极慢。反之如果格物系统提供的价值增幅很高，则精密工作台可能成为"必选"升级。

当前文档声称"更多精力 = 更多物品可处理 = 更快积累精魄点数"，但没有量化分析。

**建议**：
1. 在设计文档中增加"预期ROI分析"小节：每点额外精力每夜大约带来多少经济价值
2. 确保格物/重铸系统的数值设计已考虑精密工作台的存在，避免精力溢出（精力>物品数量时浪费）
3. 与库存扩展联动分析：如果库存只有5-6件物品但精力有6点，多出来的精力无处可用

### 9. GREEN 柜台设施维护费在"打烊结算"时序中的扣除时机

**问题**：设计文档第5.1节和昼夜循环文档有两种说法：
- 店铺升级文档 5.2节："维护费在次日晨间简报后扣除"
- 昼夜循环文档 5.6节（夜间活动时序）：第一类自动事件中"打烊结算 -- 扣除当日维护费"

**分析**：这两个时机有实质区别：
- 如果在晨间扣除：玩家夜间看到的现金余额不包含次日维护费扣除，可能导致误判（以为有钱但第二天早上被扣）
- 如果在夜间打烊时扣除：玩家在设施控制面板中调整开关后，当晚就能看到扣费效果

从代码来看，维护费扣除逻辑需要确认具体实现时机。

**建议**：统一为**夜间打烊时扣除**更合理，因为：
1. 与设施控制面板（夜间操作）形成即时反馈闭环
2. 玩家做升级/购买决策时能看到准确的可用资金
3. 更新店铺升级文档 5.2 节的描述以匹配昼夜循环文档

### 10. GREEN 储物架与精密工作台的精力-库存位平衡点

**问题**：储物架和精密工作台之间存在隐含的协同约束，但文档未分析其平衡关系。

**分析**：

| 库存位 (储物架) | 精力 (工作台) | 每夜可处理比例 |
|----------------|-------------|--------------|
| 5 (基础) | 3 (基础) | 60% |
| 6 (Lv1) | 3 (基础) | 50% |
| 7 (Lv2) | 4 (Lv1) | 57% |
| 8 (Lv3) | 5 (Lv2) | 63% |
| 10 (Lv5) | 6 (Lv3) | 60% |

假设每件物品格物消耗1精力，则在任何等级组合下，玩家每晚只能处理约50-60%的库存。这意味着需要多个晚上才能处理完所有物品，与设计文档中"顿悟延迟"原则一致。

但如果玩家优先升储物架到Lv5（10位）而不升工作台（3精力），则每晚只能处理30%的库存，可能造成挫败感。反过来，优先升工作台到Lv3（6精力）但库存只有5位，则精力浪费严重。

**建议**：
1. 在设计文档中加入"推荐升级搭配"指引，暗示两者应均衡发展
2. 或通过UI提示（如工作台精力有剩余时显示"精力过剩，考虑扩展库存"）引导玩家

### 11. GREEN 缺少升级解锁的前置条件设计

**问题**：当前所有升级从游戏第一天起就可以购买（只要有钱）。这可能导致信息过载和决策瘫痪。

**分析**：6个升级项共22个等级，全部在Day 1可见。新玩家面对$10,000初始资金和6个升级选项，可能：
- 不知道哪个优先（因为多个系统尚未体验过，如夜间格物）
- 过早投入大笔资金导致无法支付第一周医药费
- 或相反，因为不确定而完全不升级

从 Schell 的兴趣曲线角度，升级应该是渐进解锁的"奖励"，而非一次性呈现的"菜单"。

**建议**：
1. 考虑按天数或事件解锁升级项。例如：
   - Day 1-3: 仅储物架和茶具可见
   - Day 4+: 精密工作台和光谱仪解锁
   - Day 7+: 预约板解锁
   - 黑市联络网: 特定事件触发
2. 或通过"前置升级"机制：Lv2需要先有任意一个Lv1

### 12. GREEN 黑市联络网的费用增长不规则

**问题**：黑市联络网的费用序列为 $1000 / $2500 / $5000 / $8000 / $15000，增长倍率分别为 2.5x / 2.0x / 1.6x / 1.88x，不像其他升级项那样有清晰的增长规律。

**分析**：其他升级项大多保持约2.0x的恒定增长率，黑市联络网的增长率在1.6x-2.5x之间波动。这不影响功能，但让数值系统显得不够系统化。

**建议**：
1. 统一为2.0x增长率：$1000 / $2000 / $4000 / $8000 / $16000（总计$31,000，接近当前$31,500）
2. 或者如果要保持"前期便宜、后期贵"的设计，应在文档中解释原因

## 亮点

- **柜台vs后间的二分法**是优秀的设计：永久升级（后间）提供安全感和成长感，可开关升级（柜台）提供每日微决策，两者互补创造了丰富的决策层次。

- **光谱仪的"预警而非透视"设计**符合信息分层揭示原则：只告诉玩家"有异常"但不说高了还是低了，保留了鉴定系统的价值和玩家判断的空间。

- **预约板的信息层级设计**（Lv1基础外观 -> Lv5筛选偏好）是信息付费模型的优秀案例：每一级花钱买的都是"更好的决策依据"，而非直接的经济收益，让升级感觉有意义但不破坏核心玩法。

- **茶具的开关决策**与预约板的客户预览形成优秀的协同设计：预约板告诉你"明天来什么客户"，茶具让你"为难缠客户做准备"，两者联合创造了跨夜-日的策略规划深度。
