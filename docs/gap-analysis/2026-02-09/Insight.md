### Key Gaps

**Critical (design-breaking):**
1. **Layer gating not enforced (#3, #4):** The three-layer model is the core design innovation, but currently all layers are shown at once. The hook always calls `generateCustomerInsight(customer)` with default layer=1, yet the UI displays floorHint and moralContext regardless of revealedLayer. This completely bypasses the designed progression.
2. **Multi-tag mixed descriptions (#35):** Design emphasizes that contradictory multi-tag behavior (e.g., SAVVY + DESPERATE) should produce mixed descriptions. Current code picks ONE disposition via priority, losing the "human complexity" the design values.

**Significant (feature incomplete):**
3. **Training feedback not wired (#39, #40):** Complete logic exists in generator.ts but is never called. Night review does not display deal position feedback or insight accuracy hints.
4. **NPC response differentiation (#34):** NPC negotiation text should differ when insight has been used. Not implemented.
5. **Time-order hint (#22):** No UI hint when insight is used after pressure/heartstrike.
6. **Customer compendium (#42):** Entire subsystem marked [待设计] in doc but has zero implementation.
7. **Teaching customers (#41):** No tutorial scaffolding for new players.

**Minor (structural debt):**
8. **InsightHints.csv still old format (#46):** Kept as fallback but not updated to behavioral descriptions.
9. **originalFloor tracking (#21):** NegotiationPanel approximates originalFloor as current minimumAmount, which could be wrong after skill modifications.
