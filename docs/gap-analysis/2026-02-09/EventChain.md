### Key Gaps

**Missing (High Impact):**
1. **BehaviorTag floor modifiers (#19)**: The design doc specifies per-tag floor adjustments (DESPERATE -15%, SAVVY +10%, etc.) that would affect negotiation bottom lines. Only insult modifiers are implemented.
2. **BehaviorTag patience modifiers (#20)**: Per-tag patience adjustments (DESPERATE -1, STUBBORN +1) are specified but not implemented.
3. **Stage-specific behaviorTag overrides (#25)**: The design envisions NPCs evolving their behavior across story stages. The `behaviorTagOverrides` type from the design doc is absent.

**Partial (High Impact):**
4. **Tripartite mapping not wired (#23, #24)**: `behaviorTagMapping.ts` exists as a complete standalone implementation matching the design doc, but it is never imported or used. The negotiation system uses a separate, simpler mapping in `pushPull.ts`. The canonical mapping table (design doc 3.2B) and the runtime mapping are disconnected.
5. **Unified reputation pipeline (#42)**: TRANSIENT chains route rep changes through SimRules, but the negotiation system and other parts of the codebase still modify reputation directly, bypassing the event chain "unified pipeline" principle.

**Missing (Lower Impact):**
6. **Gang threat chain (#40)**: A detailed example in the design doc but no corresponding .story content.
7. **BehaviorTag mutual exclusion (#21)**: No validation prevents NAIVE+SAVVY or DESPERATE+STUBBORN combinations.
