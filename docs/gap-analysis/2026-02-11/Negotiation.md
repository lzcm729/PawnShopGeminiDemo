### Key Gaps

**Missing features (priority):**
1. **察言观色 skill** (#34): Design specifies showing concession probability tiers (low/mid/high) during negotiation. The insight system exists but does not expose concession probabilities to the player.
2. **以退为进 skill** (#35): Candidate skill for skipping an offer round in exchange for patience recovery and insult threshold relaxation. Not implemented (marked "候选" in design).
3. **寒暄破冰 skill** (#36): Candidate skill for adding patience at negotiation start. Not implemented (marked "候选" in design).

**Partial implementations (fix priority):**
1. **Screen shake on insult** (#6): Design explicitly calls for screen shake + harsh feedback on insulting offers. Feedback text exists, probability-based patience penalty exists, but no visual shake effect in the negotiation UI.
2. **Near-Ask patience modifier** (#41): Design specifies -20% patience loss when offer is close to Ask, but `calculatePatienceLossChance` only handles yield/persist/first-offer modifiers.
3. **Stolen decision granularity** (#27): Design describes a 4-option decision panel (unknowing, knowing-continue, knowing+leverage, refuse). Code has binary Accept/Reject overlay, with leverage handled separately through trait clicks.
4. **Initial patience per NPC style** (#12-15): Design ties specific patience values to push-pull styles (SOFT=5, HARD=3, etc.). Code derives patience from NPC generation + behavior tag modifiers, not directly from the push-pull style enum.
5. **First-impression instinct text** (#45): Design describes style-specific opening impressions ("这位客人眼神锐利") shown at negotiation start. No initial instinct text is displayed before the player begins adjusting their offer.
6. **SLY inflated Ask** (#46): Design says SLY NPCs have inflated initial Ask prices. Code doesn't explicitly inflate Ask for SLY/SUSPICIOUS NPCs.

**Divergent implementations:**
1. **Persist cumulative bonus** (#19): Design specifies +0%/+15%/+25% per persist count. Code uses linear +10% per count capped at +30%, giving +10%/+20%/+30% instead.
