## 2. 设计调整（来自设计评估）

在实现过程中需要体现的设计调整：

| 编号 | 调整内容 | 实现要点 |
|------|---------|---------|
| D1 | 格物道德叙事提醒 | 对当期物品格物时显示内心独白，不做机制惩罚 |
| D2 | 移除点数上限 | 三种精魄可无限积累，无上限约束 |
| D3 | 拉长顿悟周期 | 设计知识池容量使大多数物品需多夜才能顿悟 |

### 设计澄清（来自设计评估 §5）

| 编号 | 澄清内容 | 实现要点 |
|------|---------|---------|
| C1 | 三种点数无固定用途 | 修复/重铸的成本配比由**物品**决定，非操作类型 |
| C2 | 点数用于技能但不升级 | 不存在"匠心Lv2"，点数是纯货币 |
| C3 | 修复是中性操作 | UI/文案不暗示"修复=善意" |
| C4 | 重铸不一定是欺诈 | 可以是艺术加工/改良，仅伪造类有风险 |

## 3. 依赖关系分析

```
┌────────────────────────────────────────────────────────────┐
│                    物品变体与标签系统                         │
│  (底层基础设施，其他三个系统均依赖此系统)                       │
└────────────────────────────────────────────────────────────┘
                              ↓
┌────────────────────────────────────────────────────────────┐
│                    附属货币系统                              │
│  (依赖标签系统的G2材质标签来决定点数类型)                       │
└────────────────────────────────────────────────────────────┘
                              ↓
┌───────────────────────┬───────────────────────────────────┐
│       格物系统         │         重铸与修复系统              │
│  (消耗精力产出点数)     │      (消耗点数转化物品)             │
└───────────────────────┴───────────────────────────────────┘
```

**实现顺序**：标签系统 → 货币系统 → 格物系统 → 重铸/修复系统

```typescript
// 标签分组
export type StateTag = 'BROKEN' | 'DIRTY' | 'RUSTED' | 'MINT';
export type AttributeTag = 'GOLD' | 'MECHANICAL' | 'ARTISTIC' | 'VINTAGE_REAL';
export type EssenceTag = 'FAKE_HISTORY' | 'IMPERIAL' | 'TRENDING' | 'CURSED';
export type ItemTag = StateTag | AttributeTag | EssenceTag;

// 标签定义（含价值系数）
export interface TagDefinition {
  id: ItemTag;
  group: 'STATE' | 'ATTRIBUTE' | 'ESSENCE';
  valueMultiplier: number;
  displayName: string;
  icon?: string;
}

// 物品变体
export interface ItemVariant {
  id: string;
  name: string;
  description: string;
  image?: string;
  triggerTags: ItemTag[];  // 触发条件
  priority: number;        // 优先级（数字越大优先级越高）
}
```

```typescript
export type WorkshopAction = 'RESTORE' | 'REFORGE';

export interface RestoreRecipe {
  targetTag: StateTag;           // 要移除的标签
  essenceCost: Partial<EssenceBalance>;
}

export interface ReforgeRecipe {
  id: string;
  name: string;
  resultTag: EssenceTag;         // 要注入的标签

}

export interface WorkshopResult {
  success: boolean;
  itemTransformed: boolean;
  ownershipConflict: boolean;    // 重铸导致所有权冲突
}
```
