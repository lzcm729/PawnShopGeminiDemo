# 人物能力升级系统 v1.0 — 双视角整合评审

> **评审日期**: 2026-02-06
> **评审对象**: `Designer/系统设计文档/人物能力升级系统 (Character Ability System).md` v1.0
> **评审方法**: 2 个并行 game-designer Agent，分别从数值一致性和体验节奏视角评审，结果整合
> **前置评审**: `docs/人物能力升级系统-设计评估.md`（v0.x 三视角评审）

---

## 一、两位评审员共识（双方都指出的问题）

### 共识 1：明路（善行回报）是当前最弱的路径

| 视角 | 发现 |
|------|------|
| **数值** | 口口相传"高价值物品"未定义，30%概率导致高方差，日均额外收益$175-275（不确定）vs 暗路$150-300（确定） |
| **体验** | Day 5-15 存在**动机真空**——解锁惜物如人后需等2周才能看到第一笔回报，是唯一"解锁后要等两周才见效"的路径 |

**核心问题**：明路的回报链太脆弱——慈善档 → 物品过期(不可控) → 流转 → +25%售价。对比暗路：施压 → 下一笔交易立刻见效。

### 共识 2：暗路存在"无代价正反馈循环"

| 视角 | 发现 |
|------|------|
| **数值** | 融合技能"取较高系数"规则让暗路玩家几乎不受惩罚（旧影+匠心两个系数都容易在高位运转） |
| **体验** | 清白↓ → 旧影更强 → 利润更高 → 继续压榨 → 清白继续↓ → 更强，没有任何内在制衡 |

**核心问题**：暗路不是"高风险高回报"，而是"低风险高回报+额外奖励"，违反 Schell 三角化原则。

### 共识 3：道德精魄加成（+2/天）过弱

| 视角 | 发现 |
|------|------|
| **数值** | +2/天仅占日产出~60的3.3%，文档描述"一直做善事→灵韵积累快→明路先解锁"与实际影响力不符 |
| **体验** | 反馈循环"行为塑造能力"应是核心体验，但3.3%的差异不可感知 |

## 二、数值视角独特发现

### D1 🔴 压价上限与声誉调制的交互缺陷

**问题**：清白=0的暗路玩家全套技能（施压+攻心+明察秋毫2FLAW）理论降幅 **31.2%**，被20%上限截断至20%。

- 文档说"恰好在施压+攻心对绝望者时触顶(8+12=20)"，但这是**未经调制的原始值**
- 调制后施压(9.6%)+攻心(14.4%)=**24%**，已超上限，明察秋毫完全无用
- 玩家花60精魄解锁的技能在极端场景效果为零

**精确计算**：

```
场景：清白=0, 商誉=60 的暗路玩家对绝望者，2个FLAW

施压: -8% × 1.2 (旧影调制) = -9.6%
攻心(绝望者): -12% × 1.2 = -14.4%
明察秋毫(2 FLAW): -6% × max(1.2, 1.04) = -7.2%

理论总降幅: 31.2%
实际生效: 20% (cap)
浪费: 11.2%
```

**建议**：
- 明确计算顺序（先调制再cap），在第8节补充含调制的精确计算示例
- 添加UI反馈（"底价已接近保护线"）
- 确认不动声色的"不消耗耐心"效果不受cap限制（作为明察秋毫被cap时的保底价值）

### D2 🟡 日均精魄产出~60缺乏锚定

格物系统文档未明确定义每晚精力总量和每次汲取产出，~60点是假设值。所有下游数值（技能成本合理性、回本天数）都依赖这个数字。

**建议**：在经济参数文档中新增精魄经济章节，明确每晚精力、每次产出、日均期望总产出。

### D3 🟡 精魄标签分布可能导致路线不对称

三条路的精魄成本完全对称（均为160→280），但实际解锁速度取决于物品标签分布。若某类物品偏少，对应路线被不公平减速。

**建议**：约束物品数据——任意一系精魄的日均可获取量不应低于另外两系的70%。

### D4 🟡 抚慰 0AP 使用条件需严格化

0AP + 无其他成本 = 理性玩家每次都按。建议严格定义"困境中的NPC"（活跃事件链 + hope ≤ 30），让按钮出现本身成为稀缺事件。

### D5 🟡 口口相传 30% 概率的方差问题

连续10天不触发的概率约6.4%。明路后期收益对这个概率高度敏感。

**建议**：考虑伪随机机制（每次未触发+5%概率，触发后重置），消除长连败的挫败感。

### D6 🟡 施压+攻心与底价/要价的关系需文档化

技能降低的是Floor（底价），而推拉机制中NPC让步降低的是Ask（要价）。需确认Floor被降低后，`Ask >= Floor` 约束是否仍然维持。

## 三、体验视角独特发现

### E1 🟡 三条路操作层差异化不均

| 路径 | 新行动动词 | 即时反馈 | 评价 |
|------|-----------|---------|------|
| 暗路 | 施压、攻心（新按钮） | 下一笔交易见效 | **标杆** |
| 明路 | 无（仍是选慈善档） | 需等2周 | 最弱 |
| 慧路 | 无（被动信息） | 下个客户见效 | 中等 |

**建议**：
- 明路：将惜物如人改为主动技能（如送客阶段"额外关照"），给玩家"我在做不同的事"的感受
- 慧路：为洞若观火增加"流转估值"策略指导层，使信息可转化为经济决策

### E2 🟡 因果自见的疲劳风险

- Day 10+ 到游戏结束约40-80次触发
- 仅3种方向（正/中/负）× 有限文案 = 大量重复
- 与送客环节在同一时间点竞争注意力

**建议**：
- 前10次每笔触发，之后仅在影响显著时触发（hope变化>10等）
- 与送客环节视觉整合（NPC离去背影上叠加命运画面），避免双重打断
- 后期闪现内容从泛化描述升级为具体命运片段

### E3 🟡 领悟独白质量分两极

**第一梯队**（触及自我审视）：
- 攻心："最有效的武器不是真相——是对方心里那道裂缝。"
- 抚慰："你无法改变什么。但一句话，有时候比一叠钞票更有重量。"
- 因果自见："每一笔交易都不再只是数字。你看到了它的重量。"
- 洞若观火："你看着他的背影，突然知道——他不会回来了。"

**第三梯队**（停留在功能描述）：
- 破妄："真假之间的界限，在你眼中变得清晰如昼。" → 无情感重量
- 不动声色："看到一切，但什么都不表现出来。" → 只是效果总结
- 明察秋毫："瑕疵不再是坏消息。它是你手中的牌。" → 同上
- 口口相传："你不知道谁在替你说好话。但门铃又响了。" → 太轻巧

**改写方向示例**：
- 破妄 → "你看着那枚戒指，它在所有人眼中是完美的。但你看到了——镀层下的铜绿。你在想，你更羡慕看不到的人，还是看到的自己。"
- 不动声色 → "你的手摸到了裂缝，脸上却微笑着说'品相不错'。他信了。你发现，说谎原来这么容易。"
- 明察秋毫 → "你第一次对着一块划痕笑了。他注意到了你的笑容，不安地低下了头。"
- 口口相传 → "门口站着一个你从没见过的人。她说，'有个人让我来找你。说你会帮忙的。'你不记得帮过谁。"

### E4 🟡 慧路信息可操作性不足

| 信息 | 看到后能做什么 | 操作清晰度 |
|------|-------------|----------|
| 赎回意愿：高 | 给标准/低当金（反正会赎回） | 中等——但这是默认行为 |
| 赎回意愿：低 | 给更多当金？更少？ | **模糊**——两种相反策略都说得通 |
| 赎回意愿：中 | 不确定 | 低——和不知道没区别 |
| 影响方向：正/负 | 交易已完成，无法回头 | **零**——纯事后反馈 |

**建议**：
- 洞若观火：赎回意愿低时显示"流转估值"，让信息可直接转化为当金决策
- 因果自见：部分功能移到交易前——悬停不同合同档位时显示命运预兆色彩（金色/暗红），从"事后反思"变为"决策前导航"

### E5 🟡 纯系路径缺后期成长目标

纯匠心（察隐→破妄）Day 8-10就到顶了，后续15天无能力成长。

**建议**：增加"精通奖励"——只解锁单系T1+T2且未解锁其他系时，获得极致效率加成（如鉴定AP-1）。解锁其他系技能时失效，形成"极致专精 vs 广博融合"的有意义选择。

### E6 ⭐ 暗路设计亮点

暗路是整个技能树中最优雅的设计——简单的机制（降底价、隐藏情绪变化）与多个系统互动（议价推拉、鉴定、耐心、NPC反应），产生了丰富的体验变化。攻心对绝望者的NPC反应文案是"代价感"设计的标杆。

## 五、总体评价

v1.0 相比 v0.x 的提升是质的飞跃——从"27个不可感知的数值微调"到"12个质变突破"，从"0/9涉及道德"到"三条融合路径各有道德方向"。声誉调制机制（"你不是选择变成什么样的人，而是活成了什么样的人"）是全文最精彩的设计。

**当前核心风险集中在三条路径的体验质量不均衡**：

- **暗路**是标杆（新行动、即时反馈、清晰策略），但缺乏制衡导致可能成为"无脑最优解"
- **明路**概念优美但体验节奏有致命缺陷（动机真空），是最需要优先修复的路径
- **慧路**诗意十足但信息可操作性需要补强，是最需要增加"策略指导层"的路径

**v1.0 已解决的 v0.x 问题**：
- ✅ 信息技能与洞察系统冗余 → 共情改为洞察增强器
- ✅ 成本过低（276点≈4.6天）→ 提升至990点≈16.5天
- ✅ 0/9技能涉及道德 → 三条融合路径各有道德方向
- ✅ 38%最大压价破坏经济 → 20%全局上限
- ✅ 9×3增量式设计 → 12个质变突破

**v1.0 新增待解决问题**：
- 明路动机真空（P0）
- 压价上限与调制交互（P0）
- 暗路正反馈失控（P1）
- 道德加成可感知性（P1）
