# 艾玛（Emma）故事线改进计划

> 生成时间：2026-01-26
> 核心问题：**男友作为隐性压力源未被充分暗示** — 男友是促使艾玛崩溃的关键因素之一，但当前设计中玩家难以通过线索拼凑出这一真相

---

## 设计理念：隐性叙事

**目标**：让男友成为一个**从不出场但影响巨大**的角色。玩家需要通过艾玛的言行、物品故事、细节暗示来逐渐意识到——这段关系本身就是压力源。

**叙事层次**：
```
表层：艾玛在经济困境中挣扎，找工作不顺利
中层：她有一个"他"，这个人的态度似乎在变化
深层：这个人一直在精神施压，艾玛的自我价值感被逐渐摧毁
      （玩家需要拼图才能看到这一层）
```

**设计原则**：
- **展示而非讲述** — 不说"他在精神虐待她"，而是展示艾玛的自我否定
- **渐进式揭示** — 线索密度随 Stage 递增，但都是暗示而非明示
- **回顾时恍然大悟** — 第一次玩可能注意不到，但走了坏结局后回想会发现端倪

---

## 一、暗示系统设计

### 1.1 暗示类型分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **语言模式** | 艾玛习惯性的自我否定、为他人辩护 | "也许是我的问题"、"他说得对" |
| **物品故事** | 物品背后隐藏的控制痕迹 | 护肤品"说是礼物但其实是自己买的" |
| **行为细节** | 暗示被监控或控制的蛛丝马迹 | "他会看我的消费记录" |
| **外观变化** | 身体语言和外表的递进变化 | 从"精致"到"畏缩"到"麻木" |
| **缺席的存在** | 男友从不出场但处处可感 | 所有压力都来自一个看不见的"他" |

### 1.2 各阶段暗示密度

```
Stage 0 (职业装): ▪️ 轻微暗示 - 建立"他"的存在，看似正常
Stage 1 (护肤品): ▪️▪️ 物品线索 - 护肤品故事暗示关系不对等
Stage 2 (电脑):   ▪️▪️▪️ 语言模式 - 自我否定加剧，玩家开始察觉
Stage 3 (等待期): ▪️▪️▪️▪️ 邮件暗示 - 男友的"沉默"和艾玛的焦虑
Stage 4 (手表):   ▪️▪️▪️▪️▪️ 真相浮现 - 回顾时拼图完成
```

## 四、暗示效果验证清单

### 4.1 首次游玩（表层感知）

- [ ] 玩家知道艾玛有一个同居男友吗？ → 应该知道
- [ ] 玩家觉得这段关系"正常"吗？ → 可能觉得只是经济压力下的普通争吵
- [ ] 玩家能预测男友会离开吗？ → 可能注意到一些信号，但不确定

### 4.2 坏结局后回顾（深层感知）

- [ ] 玩家能列出男友的控制行为吗？
  - 翻手机检查消费
  - 经济控制（"你自己想办法"）
  - 情感否定（"看你这张脸我也累"）
  - 冷暴力（"沉默比骂我还难受"）

- [ ] 玩家能识别艾玛的语言模式吗？
  - "也许他说得对"
  - "我什么都做不好"
  - "也许是我的问题"

- [ ] 玩家会说"原来他一直在伤害她"吗？ → 设计目标

### 4.3 重玩验证

- [ ] 第二次玩时，玩家会更早注意到暗示吗？
- [ ] 相同的台词在知道真相后，感受是否不同？
- [ ] 玩家是否会产生"要是当时多帮帮她就好了"的想法？

## 七、设计反思

这个暗示系统的核心在于**让玩家自己发现真相**。

不是告诉玩家"艾玛的男友在精神虐待她"，而是让玩家在回顾时意识到：
- 为什么她总说"也许他说得对"？
- 为什么她的自信在一步步消失？
- 为什么她觉得自己"什么都做不好"？

当玩家把所有线索拼在一起，意识到"原来他一直在伤害她"的时候——那个瞬间的冲击，比任何直接的叙述都更有力量。

这也符合 Rouse 提到的"玩家的故事比设计师的故事更重要"——让玩家自己成为真相的发现者，而不是被动的接收者。

---

*此改进计划采用"隐性叙事"策略，通过细节暗示而非直接陈述，让玩家在拼图中发现艾玛崩溃的深层原因。*
