## 第一部分：跨系统共识问题

> 被 2 个以上视角/文档独立指出的问题，优先级最高。

### CS-1. 经济参数文档 v1.0 严重过时（3 个视角共识）

**来源**: 典当业务-数值 #8, 议价谈判-数值 #7, 鉴定系统-数值 #5

经济参数文档自称"权威数值来源"，但存在大面积不一致：
- 声誉三轴仍用旧名称（黑道 vs 清白）
- 利率声誉数值与声誉系统 v2.2 差异巨大（0%: HUM+5 vs +1/+2）
- 每日客户数（1 vs 4）、声誉初始值（30/20/5 vs 50/50/50）均与实际不符
- 绝当变现比例（80%）与代码（100%）矛盾

**建议**: P0 — 经济参数文档需全面升级至 v2.0，与所有子系统同步。

### CS-2. 文档与代码的数值分歧（4 个视角共识）

**来源**: 典当业务-数值 #2/#3, 议价谈判-数值 #1, 鉴定系统-数值 #1

多个系统存在"设计文档说一套、代码做一套"的问题：
- **利息计算**: 3 处不同实现（usePawnShop, useGameEngine, useFinancialProjection）
- **声誉惩罚**: 设计文档（信誉-20）vs 代码（信誉-50），一次违约是否直接 Game Over？
- **推拉概率**: 首次出价概率（100% vs 30%）、坚持加成（阶梯 vs 线性）、耐心模型（固定 vs 概率）
- **uncertainty 等级**: 设计文档用数值阈值，代码用区间比率

**建议**: P0 — 逐系统审计文档-代码一致性，以代码为准更新文档（代码已经过玩家测试）。

### CS-3. 中期（Day 8-18）动力真空（3 个视角共识）

**来源**: 昼夜循环-体验, 昼夜循环-动机, 典当业务-体验

三个视角独立指出游戏中期缺乏驱动力：
- 昼夜循环体验评审：Day 1 和 Day 25 的玩法结构几乎相同（"结构性疲劳"）
- 昼夜循环动机评审：Day 8-18 的动机弧线塌陷，缺乏阶段性里程碑
- 典当业务体验评审：7 天等待期的"中段真空"——物品典当后到期前玩家无法与之互动

**建议**: P1 — 需要设计阶段性解锁机制（新客户类型、新物品类别、新能力）打破重复感。

### CS-4. 推拉机制深度不足（2 个视角共识）

**来源**: 议价谈判-深度, 议价谈判-数值

- 深度评审指出技能天花板在数小时内收敛，缺乏情境策略层
- 数值评审指出 HARD NPC 推拉实质失效，SLY 与 CALM 区分度不足
- 两者共同指向：推拉机制在 SOFT NPC 上有趣，在其他风格上退化

**建议**: P1 — 重新校准 HARD/SLY 参数，增加 NPC 风格的策略差异化。

### CS-5. 鉴定投资 vs 盲收的策略平衡（2 个视角共识）

**来源**: 鉴定系统-决策, 鉴定系统-数值

- 决策评审：MEDIUM 状态"中空"，玩家缺乏在 MEDIUM 停下的理由
- 数值评审：LOW vs HIGH 组合效应约 38% 物品价值差距，接近"不鉴定就没法玩"

两个视角从不同角度指向同一问题：鉴定系统倾向于"要么充分鉴定要么别鉴定"的二元选择，而非设计预期的"分级投资"策略。

**建议**: P1 — 调低方向 D 幅度（1.30/0.70 → 1.15/0.85），强化 MEDIUM 状态的独立价值。

## 第二部分：按文档的独特发现与优化提议

### 一、核心设定 v1.2

| 编号 | 优先级 | 问题 | 来源 | 建议 |
|------|--------|------|------|------|
| A-1 | P0 | 道德困境随时间稀释：第20天和第1天的压价心理负担相同 | 愿景 | 设计"道德疲劳/钝化"机制，让频繁不道德行为的心理代价递减（对应现实麻木） |
| A-2 | P0 | 作恶后果不可见：压价后NPC的负面结局玩家看不到 | 愿景 | 通过邮件/新闻/事件链回传后果（"那位母亲没能凑够药费"） |
| A-3 | P0 | 缺少灰色地带：四档利率非黑即白，缺少"不完美但善意"选项 | 愿景 | 允许玩家在标准档位下通过行为（如多给一点、说安慰话）获得部分人情 |
| A-4 | P1 | 正面情绪贫乏：过度依赖道德压力，缺少成就感/温暖感 | 体验 | 增加"看到NPC因你的帮助好转"的正反馈线 |
| A-5 | P1 | 关怀选项缺乏差异化：0%和5%的体验差别不大 | 体验 | 为不同善意档位设计独特的NPC反应和后续叙事 |
| A-6 | P2 | 缺少"第二周综合征"设计：新手期过后如何维持兴趣 | 体验 | 第二周引入新机制（如赃物、复杂合同）渐进展开 |

### 五、议价谈判 v1.3

| 编号 | 优先级 | 问题 | 来源 | 建议 |

| E-1 | P0 | 文档与代码推拉概率三处偏差（首次x0.3、坚持线性、概率耐心） | 数值 | 以代码为准更新文档，概率耐心是更好的设计 |
| E-2 | P0 | HARD NPC 推拉实质失效（4.5%首次让步、5%幅度、1次上限） | 数值 | 方案A：幅度提至15-20%（难说服但大退让）；方案B：上限改为2次 |
| E-3 | P1 | 技能天花板在数小时内收敛 | 深度 | 增加情境策略层（如物品类型影响谈判、NPC 背景故事暗示策略） |
| E-4 | P1 | "坚持"操作的信息饥渴：不知道概率、不知道效果 | 深度 | 通过商人直觉提供概率暗示（"他似乎在犹豫" vs "他完全不为所动"） |
| E-5 | P1 | SLY 与 CALM 参数区分度不足（5%概率差异） | 数值 | SLY 实现 Ask 虚高机制（x1.2~1.4），降低基础概率至 20%，幅度提至 15% |
| E-6 | P1 | 保底机制（耐心<2时+20%让步）代码未实现 | 数值 | 实现并适配概率耐心模型 |
| E-7 | P2 | 5%援助档位是10%的劣化版（相同声誉，少$50利润） | 数值 | 为5%增加独有机制优势（如赎回概率+X%） |
| E-8 | P2 | 0%义举+压价可"白嫖"人情 | 数值 | 0%时设置更高底价门槛或影响NPC推拉态度 |
