## Phase 2: 玩家感知分析

### 玩家体验时间线

```
Day 1: 艾玛出现（Stage 0）
       description: "穿着精致，但眉宇间透着焦虑"
       对话: 提及衣服是"战袍"，面试入职都得穿
       玩家决策 → exitDialogue 提及男友（如果 hope 高）
       📧 即时反馈

Day 3: 📧 "近况汇报" 或 "有点焦虑"（状态更新）

Day ~5: 艾玛再次出现（Stage 1）
       description: "妆容精致但疲惫"
       greeting: 根据 hope 值变化
       exitDialogue: 提及男友（"他说只要能撑过这个月"）
       📧 即时反馈

Day ~7: 📧 "快撑不住了"（男友开始抱怨）← 铺垫！

Day ~8: 艾玛第三次出现（Stage 2）
       description: "头发凌乱，黑眼圈重"
       exitDialogue: 提及男友（"他说只要我找到工作..."）
       📧 即时反馈

Day ~10: 📧 "他最近总是很晚回家..."（男友要离开）← 铺垫！

Day 11+: Stage 3 等待期
       每次面试失败 → 📧 反馈（1次/2次/3次各有邮件）
       玩家能感知面试进程！

[分支 A] 成功 → 📧 "我拿到Offer了！" → 艾玛来赎回
[分支 B] hope<10 → 📧 "一切都结束了"（男友离开）→ Stage 4
         此时玩家已知道男友是谁！
```
