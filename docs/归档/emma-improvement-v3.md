4. **致命选择无预警**：拒绝笔记本是"致命选择"但玩家不知道

## 二、改进方案

### 2.1 [P0] Stage 4 回退机制暴露

**问题**：当艾玛崩溃后（Stage 4），如果玩家选择 charity/aid 交易手表，stage 会回退到 3，给她第二次机会。但这个机制**完全不可见**。

**当前状态**：
- `mail_emma_03b_charity` 只说"也许... 还有希望"
- `exitDialogues.grateful` 只说"你是这个城市唯一愿意好好跟我说话的人"
- 没有任何内容明确表达"你给了我第二次机会"

**修复方案**：

#### A. 修改 mail_emma_03b_charity

**原内容**：
```
老板，

谢谢你还愿意收这块表。也许... 还有希望。

我再试试。
```

**目标内容**：
```
老板，

谢谢你还愿意收这块表。

我本来已经放弃了。从你店里出来那一刻，我甚至想过去桥上吹吹风。

但你愿意帮我，哪怕是在我最落魄的时候。也许... 还有希望。

我决定再试一次。投简历、准备面试... 从头开始。

谢谢你没有放弃我。

艾玛
```

**设计意图**：
- 明确表达"你给了我第二次机会"的意图
- 让玩家知道这不是简单的交易，而是改变了艾玛的命运轨迹
- 暗示 Stage 4 的绝望程度（"想过去桥上"）

#### B. 修改 emma_04_watch_final.exitDialogues.grateful

**原代码**：
```typescript
grateful: "谢谢你。你是这个城市唯一... 愿意好好跟我说话的人。",
```

**目标代码**：
```typescript
grateful: [
    { condition: { variable: "hope", operator: ">=", value: 30 },
      text: "谢谢你。你是这个城市唯一... 愿意好好跟我说话的人。也许... 我还可以再试一次。" },
    { text: "谢谢你。你是这个城市唯一... 愿意好好跟我说话的人。" }
],
```

**设计意图**：
- 当 hope 恢复到 30 以上时（charity 交易后），暗示"再试一次"
- 让玩家在 exitDialogue 时就感知到这是一个转折点

### 2.2 [P0] 拒绝笔记本的致命性归因

**问题**：拒绝笔记本会直接进入 Stage 4 崩溃路径，但最终离开城市时没有归因到"拒绝笔记本"。

**当前状态**：
- `mail_emma_laptop_rejected` 说了没有电脑做不了面试作业 ✓
- 但后续没有任何内容将最终结局与这次拒绝关联 ✗

**修复方案**：新增邮件 `mail_emma_left_city_laptop`

**用途**：当艾玛因笔记本被拒而最终离开城市时发送。

**触发条件**：
- Stage 4 → 手表 standard/shark/reject → Stage 99
- 且 `has_laptop == 1`（表示从拒绝笔记本路径进入）

**邮件内容**：
```
老板，

我要离开这座城市了。

你还记得那天吗？我带着电脑来找你，求你帮帮我。你说不收。

我理解，也许它真的不值什么钱。但那是我最后的机会了。

没有电脑，我错过了面试作业的截止日期。没有面试，就没有工作。没有工作... 他也走了。

我不怪你。这个世界本来就是这样的。

再见。

艾玛
```

**实现方式**：
在 `emma_04_watch_final` 的 `deal_standard`、`deal_shark` 和 `onReject` 中，根据 `has_laptop` 变量选择不同邮件。

### 2.3 [P1] 利率影响暴露

**问题**：玩家选择 0%/5%/10%/20% 利率时，不知道这对 hope 有多大影响。

**当前暴露**：
- 对话情绪有差异（grateful vs resentful）
- 邮件语气有差异

**缺失的暴露**：
- 没有直接提及"利率"或"利息"

**修复方案**：在 exitDialogues 中根据利率添加提示

#### 修改 emma_01_clothes.exitDialogues

**原代码**：
```typescript
exitDialogues: {
    grateful: [
        { condition: { variable: "hope", operator: ">=", value: 65 },
          text: "谢谢！回去告诉他这个好消息，他最近也挺烦的。" },
        { text: "真的很感谢你！等我找到工作，第一时间来赎！" }
    ],
    // ...
    resentful: [
        { condition: { variable: "hope", operator: "<", value: 45 },
          text: "算了... 回去再想办法吧。" },
        { text: "没想到这行也这么黑... 算了。" }
    ],
    // ...
}
```

**目标代码**：
```typescript
exitDialogues: {
    grateful: [
        { condition: { variable: "hope", operator: ">=", value: 65 },
          text: "谢谢！这个利息... 比我想的低多了。回去告诉他这个好消息！" },
        { text: "真的很感谢你！等我找到工作，第一时间来赎！" }
    ],
    // ...
    resentful: [
        { condition: { variable: "hope", operator: "<", value: 45 },
          text: "这个利息... 算了，回去再想办法吧。（她的步伐变得沉重）" },
        { text: "没想到这行也这么黑... 算了。" }
    ],
    // ...
}
```

**设计意图**：
- 在 grateful 路径提及"利息低"，暗示这对她有帮助
- 在 resentful 路径提及"这个利息"，暗示压力来源
- 让玩家意识到利率选择有实际影响

### 2.4 [P1] job_chance 机制暴露

**问题**：玩家不知道 job_chance 的存在，不知道它如何影响面试结果。

**当前暴露**：
- fateHints 有 `job_chance >= 50` 的提示："（手里紧紧攥着一个文件夹，看起来那是她的希望）"
- 面试失败邮件提到"状态不好"

**缺失的暴露**：
- 成功邮件没有解释为什么成功

**修复方案**：修改 mail_emma_success

**原内容**：
```
老板：

告诉你一个好消息，我被那家跨国公司录取了！

还记得那台{{relatedItemName}}吗？如果那时候你像别人一样狠狠宰我一笔，或者因为我没钱就赶我走，我可能早就崩溃了。

这笔钱({{amount}})是我多付的利息，或者是... 感谢费。请你务必收下。

另外，那枚婚戒我也不打算卖了。生活好像又有希望了。

祝好，

艾玛
```

**目标内容**：
```
老板：

告诉你一个好消息，我被那家跨国公司录取了！

还记得那台{{relatedItemName}}吗？如果那时候你像别人一样狠狠宰我一笔，或者因为我没钱就赶我走，我可能早就崩溃了。

面试官说我"状态很好，很有感染力"。我想，这是因为每次从你店里出来，我都觉得这个世界还有好人。你给我的不只是钱，还有信心。

这笔钱({{amount}})是我多付的利息，或者是... 感谢费。请你务必收下。

另外，那枚婚戒我也不打算卖了。生活好像又有希望了。

祝好，

艾玛
```

**设计意图**：
- "状态很好"对应 hope 变量
- "有感染力"对应 job_chance（面试表现）
- 明确归因："你给我的不只是钱，还有信心"
- 让玩家理解自己的选择影响了艾玛的心态，进而影响面试结果

### 2.5 [P2] 苛刻路径崩溃归因

**问题**：当艾玛因为全程苛刻交易而崩溃时，邮件没有归因到"交易压力"。

**当前状态**：
- `mail_emma_boyfriend_left` 说"我一直都是错的那个人"
- 但没有提及典当交易对她的压力

**修复方案**：新增邮件 mail_emma_breaking_point

**触发条件**：
- hope ≤ 25（接近崩溃但还没崩溃）
- stage < 4（还没进入崩溃路径）
- 只触发一次

**邮件内容**：
```
老板，

我算了一下账。

当铺的利息、房租、水电... 每一笔都在催命。

有时候我会想，如果你当初给的价格再高一点，利息再低一点... 也许我不用这么拼命。

但我也知道，这不能怪你。毕竟你也是做生意的。

只是... 我快撑不住了。

艾玛
```

**设计意图**：
- 在崩溃前明确归因"典当利息"
- 玩家看到这封邮件后，会意识到自己的交易选择有影响
- 保持艾玛"不自责他人"的特点："不能怪你"
- 给玩家一个"最后的警告"，如果继续苛刻可能导致崩溃
