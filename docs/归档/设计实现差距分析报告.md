## 一、鉴定系统差距分析

### 1.1 已实现功能

| 设计特性 | 状态 | 实现位置 |
|----------|------|----------|
| 非对称区间生成 | ✅ 完成 | `systems/items/valuation.ts` |
| 渐进式逼近 (Lerp) | ✅ 完成 | `hooks/useAppraisal.ts` |
| 特征发现机制 | ✅ 完成 | `hooks/useAppraisal.ts` |
| 盲收风险提示 | ✅ 完成 | `getUncertaintyRisk()` |
| 鉴定意外事件 | ✅ 完成 | `rollAppraisalEvent()` |

### 1.2 差距分析

#### A. 鉴定意外事件概率控制 (中优先级)

**设计要求**:
- 首次鉴定不触发负面意外
- 同一物品最多触发1次负面意外
- 伪造物品不触发"鉴定失误"

**当前实现**:
- `rollAppraisalEvent()` 使用全局概率，未检查鉴定次数
- 缺少对伪造物品的特殊判断

**建议改进**:
```typescript
// 需要在 rollAppraisalEvent 中添加参数：
function rollAppraisalEvent(
  appraisalCount: number,  // 当前物品已鉴定次数
  hasNegativeEvent: boolean,  // 是否已发生过负面事件
  isFake: boolean  // 是否为伪造物品
): AppraisalEventType
```

#### B. 特征议价机制 (高优先级)

**设计要求**:
- 发现的瑕疵/伪造标签可在议价界面"使用"
- 点击特征 → 触发"情报压制"效果 → NPC心理底价下降
- 已使用特征标记为灰色，不可重复使用

**当前实现**:
- `applyLeverage()` 存在但机制简化
- 缺少特征逐个使用的交互设计
- 未实现使用后标记

**建议改进**:
- 在 `NegotiationPanel` 中添加可点击的特征标签列表
- 实现 `useTraitLeverage()` hook 管理特征使用状态

#### C. 已发现特征显示 (中优先级)

**设计要求**:
- 物品详情显示已发现特征标签列表
- 颜色区分：🔴伪造 🟡叙事 🔵瑕疵

**当前实现**:
- `revealedTraits` 已追踪
- 显示位置和视觉风格不完整

| 出价历史 | ✅ 完成 | `offerHistory` state |

### 2.2 差距分析

#### A. 商人直觉文案矩阵不完整 (中优先级)

**设计要求**:
- 系统化的文案矩阵：合同档位 × 当金区间 × NPC类型
- 覆盖所有情境组合，避免重复或缺失

**当前实现**:
- `getMerchantInstinct()` 包含约30条文案
- 部分组合使用通用回退文案

**建议改进**:
- 扩展 `INSTINCT_MATRIX` 至完整的 4×4×4 = 64 条文案
- 添加NPC类型判断（绝望型/傲慢型/平静型/狡猾型）

#### B. NPC谈判风格影响 (中优先级)

**设计要求**:
| 风格 | 特点 | 机制影响 |
|------|------|---------|
| 强硬型 | 有底气 | 侮辱阈值更高，耐心更少 |
| 软弱型 | 急需钱 | 侮辱阈值更低，容易接受低价 |
| 狡猾型 | 会演戏 | 初始期望价虚高 |
| 平静型 | 理性 | 标准行为模式 |

**当前实现**:
- `NegotiationStyle` 枚举存在
- 对谈判阈值的影响不完整

**建议改进**:
- 在 `submitOffer()` 中根据 `negotiationStyle` 调整阈值
- 实现风格对应的行为差异

#### C. 快速成交快捷键 (低优先级)

**设计要求**:
- `[期望]` - 跳到NPC期望价
- `[估值]` - 跳到估值中间价
- `[底价]` - 跳到已知底价

**当前实现**:
- 仅有滑块调整

**建议改进**:
- 添加预设按钮组件

## 优先级排序总结

### 高优先级 (影响核心体验)

1. **特征议价机制** - 让特征真正成为"攻击卡牌"
2. **客户主动续当请求** - 增加谈判维度
3. **绝当后NPC返回** - 情感代价二次交互
4. **命运预兆反馈** - 建立可学习的因果
5. **螺旋下坠情感递进** - 每次典当都是新的道德拷问
6. **邮件变量插值** - 个性化情感连接
7. **情报验证循环** - 新闻不是装饰
8. **库存日志递进式回指** - 串联命运的线
9. **日历叙事化显示** - 沉浸与精确并存
10. **声誉阈值事件** - 让声誉有实际意义
11. **探望母亲对话内容** - 具象化救母动机

1. 鉴定意外事件概率控制
